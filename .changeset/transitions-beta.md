Add `transitions` as an in-progress design beta: it reads one UI element's state change, picks a single transition pattern (a lower-overhead choice when two fit, a short list for the user when none fits), choreographs it and builds it in the project's existing stack. The selection method, choreography rules and implementation traps are adapted in its own words from transitions.dev at a pinned revision; no transitions.dev snippet or catalog is included, because its license forbids republishing the collection.
