# New skills in this fork

New skills are accepted when they solve a concrete task that existing skills do not cover. Include source metadata, focused behavior cases, docs, routing, a manifest entry when promoted, and a Changeset. See [SCOPE.md](../SCOPE.md).

The upstream policy declined outside new-skill contributions to keep its maintainer's personal catalog small. That policy is historical context, not a restriction on this fork's own skill creation and migration.
