# Publication scope

The user approved this patch release, both global installation updates, fresh-session verification, and the final report. Publish the report, release/install/catalog receipts, frozen prompts/protocol/collector code, sanitized tool receipts, model responses, response assessments, source hashes, and integrity manifest.

Keep native raw transcripts, host configuration, credentials, marketplace listings for unrelated plugins, and local execution logs in ignored `.scratch/`. Public paths use `$HOME`, `$REPO`, `$EXPERIMENT`, or `$TRIAL`. Unrelated `.playwright-cli/` artifacts are excluded. No product files, browser screenshots, private project instructions, or changes to other plugins are included.

Record unsuccessful attempts and output defects as failures; do not replace them with later successes. Report host list-price estimates separately from unknown actual billing.
