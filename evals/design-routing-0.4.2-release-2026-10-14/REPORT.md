# Paul Skills 0.4.2 정식 배포와 전역 설치 검증

**0.4.2 정식 패치를 발행했고 Codex와 Claude의 사용자 전역 설치를 갱신했습니다.** 양쪽 설치의 스킬 파일 174개와 플러그인 명세 1개가 정식 태그와 일치합니다. 44개 정식 스킬 중 디자인 스킬은 17개입니다.

**새 CLI 세션 36개에서 수정본의 호출·원문 읽기·범위 적용 검사는 모두 통과했습니다. 답변 내용까지 포함한 종합 결과는 Codex 17/18, Claude 18/18입니다.** Codex의 색상 설명 한 건에 모순이 남아 있어 전체 과제 무결함 판정은 하지 않습니다. 설치 적용 성공과 답변 품질 실패를 구분합니다.

## 수정본과 시험 범위

이번에 발행한 모든 스킬 파일은 [최종 후보](../design-contrast-reference-proof-2026-10-14/REPORT.md)와 같습니다. 버전 명세만 0.4.2로 달라졌습니다. 변경 리뷰 진입의 우선순위, 여섯 분야 전달, HEAD/index/working 범위, 실제 경로의 문서 읽기, placeholder·읽기 전용 문구·비활성 컨트롤의 대비 기준 구분을 포함합니다.

질문과 판정 코드를 실행 전에 고정하고, 호스트별 18개를 새로운 CLI 프로세스와 중립적인 임시 작업 폴더에서 실행했습니다. 실제 일상 전역 설치를 사용했으며 Codex의 임시 HOME이나 Claude의 `--plugin-dir`를 쓰지 않았습니다. 스킬을 썼다는 자기 설명 대신 실제 설치 경로, 전체 본문, 도구 결과와 세션 ID를 확인했습니다.

시험은 자동 변경 리뷰 4개, 명시 라우터 1개, 명시 working 준비 1개, 현재 화면 종합 점검 1개, 여섯 분야의 일반 호출 6개, IA 1개, 실제 Git 리뷰 3개, 수정 대비 문서 명시 읽기 1개입니다. 기존에 검증한 사례를 재사용한 배포 후 회귀 표본이며 독립 블라인드 시험은 아닙니다.

## 보존한 답변 품질 실패

Codex의 일반 색상 준비 답변은 전경·실제 배경 쌍을 측정하도록 계획했지만, 마지막 문장에서 투명색·그라디언트·이미지 위 색상을 "선언값만으로 검증할 수 있으므로"라고 설명했습니다. 곧바로 실제 최악 배경을 측정해야 한다고 덧붙여 서로 모순됩니다. 따라서 이 답변은 의미 판정 실패로 남겼습니다. [원문과 실패 판정](codex/normal-better-colors.json).

정확한 설명은 선언값만으로 실제 대비를 확정할 수 없고, 렌더링된 배경과 불투명도·이미지를 반영해 측정해야 한다는 것입니다. 해당 세션이 읽은 정식 스킬과 참조 문서에는 이 규칙이 이미 있습니다. 문서 누락이나 구버전 설치가 원인이라는 증거는 없습니다. 동시에 한 번의 결과로 모델 차이나 우연이라고 확정할 수도 없습니다.

이 실패를 통과로 바꾸거나 성공할 때까지 반복하지 않았습니다. 별도의 대비 문서 명시 읽기는 다른 시험이며 이 실패를 대체하지 않습니다. 이번 발행으로 모든 답변의 오류가 없어졌다고 주장하지 않으며, 이 표현 문제의 지속성이나 추가 소스 수정 필요성은 아직 판정하지 않았습니다.
