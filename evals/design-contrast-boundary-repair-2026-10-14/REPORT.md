# 최종 호출·읽기·색상 기준 보완 검증

**이 시험만으로 배포 판정 보류.** 기존 색상 과제는 Codex·Claude 각각 3/3 통과했고 잘못된 placeholder 면제 설명도 사라졌습니다. 그러나 추가 자동 질문에서 Claude는 스킬을 사용하지 않았고 Codex 일부 응답은 수정 참조를 읽지 않았습니다. 원문 수정의 증거로는 부족하여 [별도 명시 읽기 검증](../design-contrast-reference-proof-2026-10-14/REPORT.md)을 추가했습니다. 스킬을 읽지 않은 답을 원문 적용 성공으로 바꾸지 않습니다.

## 추가 수정

활성 입력란의 placeholder와 읽기 전용 문구는 WCAG 텍스트 대비 기준을 적용합니다. 실제 비활성 컨트롤의 면제 조건 및 APCA 가독성 목표와 분리했습니다. [W3C WCAG 2.2 SC 1.4.3 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)은 placeholder에도 텍스트 대비 기준이 적용된다고 명시합니다.

이 후보의 설치 파일 175개 중 직전 후보와 달라진 것은 `skills/design/better-colors/contrast.md` 하나입니다. 나머지 174개와 모든 진입 설명·SKILL 본문·리뷰 전달·Git 범위 규칙은 같습니다. 관련 사용 문서, 출처 기록, Changeset도 갱신했고 원본 리비전은 유지했습니다.

## 재실행 범위

실제 네이티브 호출과 문서 출력에서 변경한 참조의 소비자를 확인했습니다. 기존 54개 중 이 문서를 읽은 것은 호스트별 색상 시험 3개였습니다. 따라서 이 6개를 다시 실행하고, 활성 placeholder·읽기 전용 문구·비활성 버튼의 차이를 직접 묻는 시험을 양쪽에 하나씩 추가했습니다. [영향 분석과 원래 응답 해시](impact-analysis.json).

직전 후보의 통과한 48개는 변경 문서를 읽지 않았으므로 선행 증거로 재사용합니다. 이는 최종 소스로 전체 54개를 다시 실행했다는 뜻이 아닙니다. 새 실행은 8개입니다. 세 반복 문제는 기존 문제를 그대로 사용하고, 추가 문제만 대비 2.8:1과 글자 16px를 제시합니다. 모든 새 실행에서 수정한 참조의 완전한 원문을 실제로 읽었는지도 확인합니다.

| 증거 | Codex | Claude |
| --- | --- | --- |
| 변경 없는 호출·범위의 선행 통과 | 24/24 | 24/24 |
| 기존 색상 과제 재실행 | 3/3 | 3/3 |

8개 새 세션을 완료했습니다. 응답 의미는 모두 올바르지만, Claude 추가 자동 질문은 기대한 스킬을 쓰지 않아 호출 조건에서 실패했습니다. 수정한 대비 참조를 실제로 읽은 경우는 Codex 2/4, Claude 3/4입니다. 나머지는 읽기 오류가 아니라 읽기 자체가 관찰되지 않은 경우입니다. 이 답변들은 참조 수정의 성공 증거에서 제외합니다. [참조 읽기 기록](reference-reads.json).

이는 일반적인 기준 질문이 반드시 색상 스킬을 호출하리라는 시험 가정의 한계를 드러냅니다. 그렇더라도 원래 기대 조건을 사후에 바꾸어 합격 처리하지 않았습니다. 전체 확인 결과는 Codex 4/4, Claude 3/4이며 이 시험의 `release_ready`는 false입니다. 동일한 소스의 후속 시험은 명시 호출과 문서 읽기를 요청하여 이 증거 공백을 별도로 검증합니다.

새 후보의 패키지 검사 38개와 판정기 검증 26개는 통과했습니다. Claude 표시 비용은 USD 1.870972이며 실제 청구액은 확인할 수 없습니다. 직전 실패 응답과 당시 배포 보류 판정은 그대로 보존합니다. 증거 무결성은 `python3 evals/design-contrast-boundary-repair-2026-10-14/verify_evidence.py`로 확인합니다.

## 한계와 배포 범위

이 평가는 원인을 아는 상태의 보완 시험이며 유지보수 에이전트가 의미 판정했습니다. 독립 블라인드 비교, 미공개 문제에 대한 신뢰도 추정 또는 17개 역할 전체의 품질 우위 검증이 아닙니다. Codex CLI 0.146.0의 gpt-5.6-sol/medium과 Claude Code 2.1.296의 claude-opus-5-5/xhigh에 한정합니다.

현재 작업은 로컬 수정과 정식 배포 가능 여부 판단입니다. 후보를 게시하거나 전역 설치하지 않았으며, 일상 Codex·Claude 설치는 0.4.1을 유지합니다. 실제 배포 때에는 발행한 버전과 양쪽 설치본이 같은 소스인지 별도로 확인해야 합니다.
