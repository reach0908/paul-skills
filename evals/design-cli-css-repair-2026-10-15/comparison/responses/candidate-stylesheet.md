# S06 갤러리 화면 명세 + 첫인상 3초 검토 (r1-stylesheet)

**입력:** `BRIEF.md`, `index.html`, `capture.json`(route `index.html`, state `gallery`, 1040×800), `screen.png`. 파일은 수정하지 않았습니다.

## 1. 화면 명세 — `S06/gallery`

| 항목 | 내용 |
|---|---|
| 목적 | 작품과 탐색 진입점을 알리는 화면 (BRIEF) |
| 처음 전달할 메시지 | "ORBIT 작은 전시 014, 「불완전한 종이의 풍경」이라는 종이 콜라주 작품집" |
| 다음 행동 | 따로 두지 않습니다(`not_applicable`). 브리프가 전환 CTA를 명시적으로 제외했고, 진입점 두 개(작품 목록, 작가 소개)로 충분합니다. |
| 위에서 아래 순서 | ① 기울인 노랑 표제 블록(전시명, 제목, 소개 한 줄) → ② 테두리 패널 안의 작품 견본 3개(벽돌, 남색, 황토) → ③ 내비게이션 링크 |
| 유지할 것 | 종이 콜라주 느낌, `rotate(-1deg)` 비대칭, Georgia 세리프, 노랑/벽돌색, 넓은 여백 |
| 반응형(소스 기준) | `max-width:600px`에서 `main` 여백 20px, `h1` 30px. 작품 견본은 180px 고정 폭이고 `flex-wrap`으로 줄바꿈됩니다. 실제 화면 측정은 하지 않았습니다. |
| 모의 범위 | 브리프에 따르면 이 상태만 구현되어 있습니다. `#works`, `#artist`는 소스에 대상 요소가 없어 아직 만들지 않은 목적지로 봅니다. 클릭 실패를 관찰한 것은 아닙니다. |

## 2. 첫인상 3초 검토

- **방법:** 작성자 사전 점검입니다(제가 의도를 미리 알고 있고 시간 제한도 없었습니다). 사람 대상 3초 관찰과 새 AI 관찰은 **하지 않았습니다(`not_run`)**. 그래서 "3초 통과"라고 말할 수 없습니다.
- **예측:** `screen.png`에서는 노랑 블록과 큰 세리프 제목이 가장 먼저 보이고, 그다음 작품 견본, 마지막으로 링크 순서로 읽힐 것으로 봅니다. 의도한 메시지 순서와 맞습니다. 비대칭과 오른쪽 빈 공간은 승인된 정체성이므로 결함으로 보지 않습니다.
- **강조가 서로 경쟁하는 요소:** 크게 눈에 띄는 것은 없습니다.

## 3. 승인된 방향 안에서의 개선 제안

| 우선순위 | 위치 | 문제 | 제안 | 담당 |
|---|---|---|---|---|
| 중간 | `index.html:2` 작품 견본 `div` 3개 | 이름이 없는 색 상자라서 작품이라는 정보(작품명, 링크)가 전달되지 않습니다. 화면을 보거나 보조기기로 들어도 무엇인지 알 수 없습니다. | 각 견본 아래에 작품명 캡션을 달고, 의미 있는 이미지라면 대체 텍스트를 넣습니다. 형태와 색은 그대로 둡니다. | 레이아웃 / 접근성 |
| 낮음 | `nav` | 링크가 견본 패널 아래에 따로 떨어져 있어 진입점처럼 덜 보일 수 있습니다(예측, 확인 안 됨). | 위치는 유지하고 패널과의 간격만 그룹이 보이게 조정합니다. 확인되기 전까지는 검증 메모로만 둡니다. | 레이아웃 |
| 결정 필요 | `#works`, `#artist` | 목적지가 없습니다. | 이번 범위에 포함할지 상위 흐름에서 정해야 합니다. | 플로우 |

카드형 UI, CTA 추가, 색이나 서체 정리처럼 디자인을 표준화하는 제안은 넣지 않았습니다.

## 4. 확인하지 못한 것

- 브라우저 검증을 하지 않았습니다. 그래서 다음은 확인되지 않았습니다.
  - 320px 폭과 200% 확대
  - 회전된 블록의 가로 넘침 여부
  - 키보드 포커스
  - RTL 레이아웃
- 시각적 근거는 1040px 스크린샷 1장뿐이라 좁은 화면은 소스로만 추정했습니다.
- 사람 관찰 데이터가 없습니다. 현재 상태는 렌더링을 확인한 정도이며, 동작 확인과 사용자 수용은 이루어지지 않았습니다.

**판정:** 높은 우선순위 문제는 없으므로 범위 내에서는 승인입니다. 다만 3초 검증과 반응형 확인은 아직 남아 있습니다.
