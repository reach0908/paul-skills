# S06 / gallery / r1-important: 화면 명세와 첫인상 검토

**대상:** `index.html` (state `gallery`, revision `r1-important`), `screen.png` (1040×800)
**전제:** BRIEF에 따르면 이 화면은 합성 fixture이고, 구현된 상태는 gallery 하나뿐입니다. 사람 관찰은 수집되지 않았습니다.

## 1. 화면 명세

| 항목 | 내용 |
|---|---|
| 목적 | 작품과 탐색 진입점을 알리는 갤러리 |
| 의도한 첫 메시지 | "ORBIT 작은 전시 014 — 불완전한 종이의 풍경" |
| 다음 행동 | 해당 없음. 갤러리 화면이고, BRIEF가 전환 CTA를 배제합니다. |
| 보존할 요소 | 노랑 표제 블록(Georgia 세리프, −1° 회전), 벽돌·남색·갈색 타일 3개(3px 테두리 패널 안), 내비게이션 링크 "작품 목록"·"작가 소개" |
| 정보 위계(DOM 순서 = 시각 순서) | 전시 번호 → h1 → 부제 → 작품 조각 → 탐색 링크 |
| 목업 경계 | `#works`, `#artist`의 대상 요소가 소스에 없습니다. BRIEF가 다른 상태를 범위 밖으로 두므로 결함이 아니라 미구현(pending)으로 기록합니다. |

**반응형 (소스 기준, 실측 아님)**
- 1040px: 600px 미디어 조건이 맞지 않습니다. 따라서 h1의 인라인 `font-size:64px`이 적용됩니다. 캡처와 일치합니다.
- ≤600px: `h1{font-size:30px!important}`가 인라인 64px을 이깁니다(important 선언이 important가 아닌 인라인 스타일보다 우선). 결과는 h1 30px, main 여백 20px입니다.
  - 표제가 1040px 대비 절반 이하로 줄어 첫 메시지 강도가 약해질 수 있습니다. 측정 전이므로 예측입니다.
- 타일은 180px 고정폭이고 `flex-wrap`이라 좁은 화면에서 줄바꿈됩니다. 320px에서 넘침이 생기는지는 측정하지 않았습니다.

## 2. 첫인상 3초 검토

| 방법 | 상태 |
|---|---|
| 사람 3초 노출 | `not_run` (참가자 없음) |
| 새 AI 관찰자 | `not_run` (추가 참가자 불가) |
| 작성자 사전 점검 (시간 제한 없음, 의도를 알고 봄) | 실행 |

**사전 점검 예측:**
- 노랑 블록과 64px 세리프 h1이 가장 먼저 읽힙니다. 전시 제목이라는 의도와 맞습니다.
- 타일 3개는 이름·캡션·대체 텍스트가 없는 빈 `div`입니다. 작품이 아니라 색 견본으로 읽힐 위험이 있습니다(예측).
- 탐색 링크는 800px 높이 안에 보이지만 표제와 패널보다 시각적 비중이 작습니다. 다만 갤러리 화면이라 이것만으로는 문제의 근거가 되지 않습니다.

## 3. 승인된 방향 안의 개선 제안 (적용하지 않음)

1. **작품 식별(중간):** 타일마다 짧은 작품명 캡션이나 대체 텍스트를 붙입니다. 콜라주 배치와 색은 그대로 둡니다. "작품" 메시지를 전달하려면 필요하지만, 작품명은 아직 정해지지 않았습니다(`unknown`).
2. **모바일 표제 크기(검증 필요):** `!important` 30px가 의도된 값인지 확인해야 합니다. 의도가 아니라면 미디어 규칙에서 표제 전용 크기를 따로 정합니다. 실측 전까지는 확인 사항으로만 둡니다.
3. **바꾸지 말 것:** 비대칭 회전, 패널 우측의 빈 공간, 세리프, 노랑/벽돌색. 카드형으로 정규화하거나 CTA를 추가하지 않습니다.

## 4. 확인 한계

- 브라우저 실측(600px 이하, 320px, 200% 확대, 키보드 포커스, RTL)은 모두 `Not verified`입니다.
- 위 판단은 사람이나 새 관찰자의 이해를 입증하지 않습니다. 이 검토로 "3초 통과"라고 말할 수 없습니다.
- 사용자 승인은 아직 없습니다. 지금 확인된 것은 1040px에서 렌더링된다는 것뿐입니다.
- 파일은 수정하지 않았습니다.

**판정:** 소스나 캡처로 입증된 HIGH 문제는 없습니다. 작품 식별은 미결 결정으로 남깁니다.
