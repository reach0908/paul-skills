# S06 갤러리 화면 명세 및 첫인상 검토 (r1-stylesheet)

## 1. 기준 입력

| 항목 | 값 |
|---|---|
| 화면/상태 | S06 / `gallery` |
| 리비전 | `r1-stylesheet` (capture.json) |
| 경로·뷰포트 | `index.html`, 1040×800 (`screen.png`) |
| 구현 범위 | 제공된 상태 하나만 구현됨 (BRIEF.md:2) |

## 2. 화면 명세

- **목적:** 작품을 소개하고 탐색으로 들어가는 진입점을 보여 주는 갤러리입니다 (BRIEF.md:1).
- **처음 전달할 메시지:** 이 화면이 「불완전한 종이의 풍경」이라는 종이 콜라주 작품집(ORBIT 작은 전시 014)이라는 점입니다.
- **다음 행동:** 해당 없음. 브리프가 전환 CTA를 명시적으로 제외합니다. 탐색 링크 두 개가 진입점 역할을 합니다.
- **콘텐츠 순서 (DOM 순서와 화면 순서가 같음):**
  1. 기울어진 노랑 타이틀 블록: 전시 번호, H1, 한 줄 소개
  2. 굵은 테두리 안의 작품 띠: 벽돌색·남색·베이지 조각 3개
  3. 탐색: `작품 목록`(#works), `작가 소개`(#artist)
- **유지할 요소:** 종이 콜라주, 비대칭 배치, 세리프 타이틀, 노랑/벽돌색 팔레트, 작품 띠 오른쪽의 빈 공간, 두 탐색 링크와 포커스 아웃라인(`a:focus-visible`)
- **반응형:** 600px 이하에서는 여백 20px, H1 30px로 바뀝니다. 작품 띠는 `flex-wrap`으로 줄바꿈됩니다. 세 영역의 순서는 그대로 유지하는 것을 권장합니다.
- **목업 범위:** `#works`, `#artist` 대상 요소가 소스에 없습니다. 단일 상태 픽스처이므로 미구현 목적지로 기록하며, 결함으로 판정하지는 않습니다.

## 3. 첫인상 3초 검토

| 방법 | 상태 |
|---|---|
| 작성자 사전 점검 (정적 스크린샷, 시간 측정 없음, 의도를 아는 상태) | 수행 |
| 새 맥락 AI 관찰 | `not_run` |
| 사람 3초 노출 | `not_run` (참가자 없음) |

사전 점검에서 예측한 결과는 다음과 같습니다. 측정 결과가 아닙니다.

- 가장 먼저 보이는 것은 화면 상단 약 40%를 차지하는 노랑 블록과 세리프 H1입니다. 전시 제목과 "디지털 작품집"이라는 성격이 먼저 읽힐 가능성이 높습니다.
- 두 번째로는 굵은 테두리의 작품 띠가 보입니다. 다만 단색 사각형이라 작품이라는 점은 맥락으로만 짐작됩니다.
- 탐색 링크는 첫 화면 안(y≈570)에 있고 밑줄로 링크임이 드러납니다. 시각적 비중은 가장 작지만 갤러리 화면에서는 적절한 우선순위입니다.
- 의도와 예측 사이에 뚜렷한 불일치는 확인되지 않았습니다. 강조가 경쟁하는 지점도 없습니다.

## 4. 개선 제안 (승인된 방향 안에서)

**차단할 만한 발견은 없습니다.** 빈 공간과 비대칭은 승인된 정체성이므로 정규화하지 않습니다. CTA, 카드형 구성, 장식도 추가하지 않습니다.

확인되지 않은 위험이라 심각도 등급에서는 제외하고 검증 메모로만 남깁니다.

1. **작품 조각에 이름이 없습니다** (`index.html:2`의 `div` 3개). 실제 이미지로 바꿀 때 작품명을 대체 텍스트로 넣어야 화면 낭독기 사용자도 작품을 알아볼 수 있습니다. better-accessibility로 넘길 사항입니다.
2. **링크 목적지가 없습니다** (`#works`, `#artist`). 해당 상태를 구현하는 쪽으로 넘기는 열린 결정입니다.

## 5. 확인 한계

- 브라우저를 쓸 수 없어 클릭, 키보드 이동, 320px 폭, 200% 확대, RTL은 모두 확인하지 못했습니다.
- 600px 이하 반응형은 CSS로만 읽었고 화면으로 보지는 않았습니다.
- 사람이나 새 맥락 AI의 관찰은 없습니다. 따라서 "3초 테스트 통과"라고 할 수 없고, 사용자가 수용했다는 근거도 아직 없습니다.
- 정리하면 이 화면은 **렌더링은 확인됐고, 동작은 확인하지 못했으며, 사용자 수용은 아직 판단할 근거가 없습니다.**

파일은 수정하지 않았습니다.
