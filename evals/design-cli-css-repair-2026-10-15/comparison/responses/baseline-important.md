# S06 갤러리 (r1-important) 화면 명세와 첫인상 3초 사전 점검

파일은 수정하지 않았습니다. 사람이나 AI의 실제 3초 관찰은 하지 않았고, 아래 판단은 화면 이미지와 소스를 보고 제가 예측한 것입니다.

## 입력 기준
- **화면:** `index.html`, `gallery` 상태, 리비전 `r1-important`
- **자료:** `capture.json` 기준 1040×800 캡처인 `screen.png`, `BRIEF.md`
- **범위:** 구현된 상태는 `gallery` 하나뿐입니다(BRIEF 2행).

## 화면 명세
| 항목 | 내용 |
|---|---|
| 목적 | 작품과 탐색 진입점을 알리는 갤러리(BRIEF 1행) |
| 전달할 첫 메시지 | "작은 전시 014 「불완전한 종이의 풍경」, 종이 콜라주 작품집" |
| 다음 행동 | 해당 없음. 이 화면은 전환 CTA를 두지 않습니다(BRIEF). 탐색 링크가 행동 역할을 합니다. |
| 유지할 정보와 조작 | 전시 번호, 제목, 한 줄 소개, 작품 3점, `작품 목록`·`작가 소개` 링크 |
| 위계 | ① 노란 기울어진 히어로 ② 테두리 안 작품 3점 ③ 텍스트 링크 2개. 화면 순서와 DOM 순서가 같습니다. |
| 반응형 | 600px 이하에서 `h1{font-size:30px!important}`가 인라인 64px를 덮어씁니다(`index.html:1`). 화면에서는 확인하지 못했습니다. |
| 목업 경계 | 링크 대상 `#works`, `#artist`가 소스에 없습니다. 제공 범위 밖의 화면이라 결함이 아닌 미구현으로 기록합니다. |

## 첫인상 3초 사전 점검 (작성자 예측, 시간 측정 없음)
- **예측:** 시선은 노란 블록의 제목에 먼저 갑니다. 다음으로 색면 3개가 "작품"으로 읽힐 가능성이 높습니다. 전시 번호와 소개 문장 덕분에 "전시·작품집"이라는 목적도 전달될 것으로 봅니다.
- **의도와의 차이:** 실제 관찰이 없어 확인된 차이는 없습니다.
- **승인된 정체성 유지:** 비대칭, 회전, 세리프, 노랑/벽돌색, 오른쪽 빈 공간은 승인된 정체성이므로 그대로 둡니다. 근거 없이 정리하거나 CTA를 추가하는 제안은 하지 않습니다.

## 개선 제안 (승인된 방향 안에서만)
심각도 순으로 정리할 만큼 근거가 확인된 결함은 없습니다. 다음 리비전에서 확인할 위험만 적습니다.
1. **링크 위치:** 탐색 링크가 작품 아래 y≈670에 있어 800px 높이에서 겨우 보입니다. 더 낮은 화면에서는 첫 화면 밖으로 밀릴 수 있습니다. 실제로 확인되면 링크를 히어로 바로 아래나 안쪽으로 올리는 정도의 배치만 조정합니다. 링크의 스타일과 정체성은 바꾸지 않습니다.
2. **작품 이름:** 색면 3개에는 대체 텍스트나 제목이 없습니다. 실제 작품 이미지로 바꿀 때 `alt`나 캡션을 붙이는 것이 좋습니다. 접근성 담당 영역입니다.
3. **좁은 화면의 제목 크기:** 600px 이하에서 `!important`로 제목이 64px에서 30px로 줄어듭니다. 이것이 의도인지 리비전 소유자에게 확인이 필요합니다.

## 확인 한계
| 확인 항목 | 상태 |
|---|---|
| 사람 3초 관찰 | `not_run` (참가자 없음) |
| 새 AI 관찰 | `not_run` |
| 브라우저, 키보드, 좁은 화면(320px), 200% 확대, RTL | `Not verified` |
| 링크 클릭 동작 | 소스에서 대상이 없음만 확인했고, 클릭해 보지는 않았습니다. |

## 상태 구분
- **렌더링:** 1040px 캡처 1장으로 확인했습니다.
- **동작 확인:** 하지 않았습니다.
- **사용자 수용:** 하지 않았습니다.
- **판정:** HIGH 결함이 확인되지 않아 Approve입니다. 단, 이 판정은 정적 자료 범위에 한정되고 사람이 이해했다는 증명은 아닙니다.
- **아직 결정이 필요한 것:** `#works`·`#artist` 목적지 구현 여부, 좁은 화면의 제목 크기.
