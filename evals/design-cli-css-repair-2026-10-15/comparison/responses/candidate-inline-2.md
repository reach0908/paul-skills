# S06 / gallery / r1: 화면 명세와 첫인상 검토

**입력:** `BRIEF.md`, `index.html`, `capture.json`(route `index.html`, state `gallery`, r1, 1040×800), `screen.png`
**방법:** 작성자 사전 검토(AI)만 했습니다. 시간 제한 없이 보았고, 화면 의도를 이미 알고 본 상태입니다. 브라우저 확인, 새 관찰자 관찰, 사람 대상 3초 테스트는 모두 하지 못했습니다. 파일은 수정하지 않았습니다.

## 1. 화면 명세

| 항목 | 내용 |
| --- | --- |
| 목적 | 작품과 탐색 진입점을 알리는 갤러리 (BRIEF) |
| 의도한 첫 메시지 | "ORBIT 작은 전시 014, 「불완전한 종이의 풍경」이라는 종이 작품집" |
| 다음 행동 | 해당 없음. 갤러리 화면이라 주 CTA를 두지 않습니다(BRIEF에서 전환 CTA를 제외함). |
| 콘텐츠 위계 | ① 노랑 세리프 표제 패널(-1° 회전) → ② 테두리 안 작품 조각 3개 → ③ 탐색 링크 「작품 목록」, 「작가 소개」 |
| 유지할 요소 | 종이 콜라주, 비대칭, 세리프, 노랑/벽돌색, 두 탐색 링크, 링크 포커스 표시(`a:focus-visible` 3px) |
| 반응형(소스 기준, 실측 아님) | 600px 이하에서 `main` 여백은 20px가 됩니다. 하지만 h1은 인라인 `font-size:64px`가 미디어 규칙 `h1{30px}`보다 우선하므로 좁은 화면에서도 64px로 유지됩니다. 작품 칸은 고정 180px이고 `flex-wrap`으로 줄바꿈됩니다. |
| 목업 경계 | `#works`, `#artist` 이동 대상이 소스에 없습니다. BRIEF에 "제공된 상태만 구현"이라고 되어 있으므로 결함이 아니라 아직 구현하지 않은 부분으로 기록합니다. |

## 2. 첫인상 검토 (AI 사전 검토이며 3초 테스트가 아님)

- **예상:** 표제 패널이 가장 먼저 눈에 들어와 전시 이름과 "작품집"이라는 성격이 전달될 가능성이 큽니다. 작품 조각은 표제 다음으로 보이고, 탐색 링크는 1040×800 첫 화면 안(y≈670)에 들어옵니다.
- **의도와 어긋난 점:** 근거를 갖춰 확인한 것은 없습니다. 비대칭 배치, 오른쪽 빈 공간, 회전은 승인된 정체성이므로 정리 대상이 아닙니다.
- **사람 대상 3초 테스트:** 실행하지 못했습니다. **새 AI 관찰:** 실행하지 못했습니다. 따라서 "3초 통과"라고 할 수 없습니다.

## 3. 개선 제안 (승인된 방향 안에서)

차단할 만한 레이아웃 결함은 확인되지 않아 **필수 수정은 없습니다**. 아래는 확인 후 판단할 항목입니다.

1. **좁은 화면 표제 크기:** 인라인 64px 때문에 모바일 축소 규칙이 적용되지 않습니다. 320px 폭에서 「종이의 풍경」 줄이 넘치거나 잘리는지 측정해야 합니다. 문제가 확인되면 인라인 크기를 클래스로 옮겨 미디어 규칙이 적용되게 하는 정도로 충분합니다. 지금은 예측일 뿐입니다.
2. **작품 조각에 정보 없음:** 세 칸은 색만 칠한 `div`이고 제목도 대체 텍스트도 없습니다. 이번 픽스처에서는 자리표시로 보입니다. 실제 작품을 넣을 때 작품명이나 대체 텍스트를 붙일지는 콘텐츠 담당이 결정할 사항입니다.
3. **탐색 링크 위치와 대비:** 링크는 맨 끝에 작게 있지만 첫 화면 안에 보이고 밑줄이 있습니다. 근거 없이 키우거나 CTA처럼 바꾸지 않습니다.

## 4. 근거와 확인 한계

- **소스로 확인한 것:** 인라인 스타일이 미디어 규칙보다 우선한다는 점, 이동 대상이 없다는 점, 포커스 스타일, DOM 순서와 화면 순서가 같다는 점.
- **화면으로 확인한 것:** `screen.png` 한 장(1040×800)뿐입니다.
- **확인하지 못한 것:** 320px 폭과 200% 확대, -1° 회전 때문에 가로 넘침이 생기는지, 키보드 이동, RTL, 사람이나 새 AI 관찰자의 첫인상, 사용자 수용 여부.
- **상태 구분:** 렌더링은 r1 스크린샷으로 확인했습니다. 동작은 확인하지 못했습니다. 사용자 수용도 확인하지 못했습니다.
