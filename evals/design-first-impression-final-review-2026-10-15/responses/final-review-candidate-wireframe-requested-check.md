# S06 / gallery / r1 화면 명세와 첫인상 검토

**대상:** `index.html`, gallery 상태, r1. 화면은 `screen.png`(1040×800, `capture.json` 기준)만 봤습니다.
**확인 방법:** 소스와 스크린샷을 정적으로 보고 제가 직접 예측했습니다. 브라우저와 참가자는 쓰지 않았고, 파일도 수정하지 않았습니다.

## 1. 화면 명세

| 항목 | 내용 |
|---|---|
| 목적 | 작품과 탐색 진입점을 알리는 갤러리 (`BRIEF.md:1`) |
| 첫 메시지 | "ORBIT 작은 전시 014, 「불완전한 종이의 풍경」이라는 종이 콜라주 작품집" |
| 다음 행동 | 따로 두지 않음. 갤러리라서 전환 CTA는 브리프상 제외 대상입니다. 탐색 진입점 두 개(작품 목록, 작가 소개)가 그 자리를 대신합니다. |
| 콘텐츠 순서 (DOM과 화면 순서가 같음) | ① 기울어진 노랑 표제(세리프, 64px) → ② 굵은 테두리 안의 작품 색면 3개 → ③ 링크 `#works`, `#artist` |
| 반드시 유지할 것 | 종이 콜라주, 비대칭(-1° 회전), 세리프, 노랑/벽돌색, 탐색 링크 2개 |
| 좁은 화면 | `flex-wrap`이라 색면이 줄을 바꿔 쌓입니다. 600px 이하에서는 여백만 줄어듭니다. 링크는 계속 맨 아래에 있습니다. |
| 목업 범위 | 구현된 상태는 이 하나뿐입니다 (`BRIEF.md:2`). |

## 2. 첫인상 3초 검토

| 방법 | 결과 |
|---|---|
| 작성자 사전 점검 (제 예측, 시간 측정 없음, 의도를 미리 알고 봄) | 표제가 가장 먼저 눈에 들어올 것으로 예상합니다. 노랑 면적과 64px 세리프 때문입니다. 그다음 색면 3개, 마지막이 링크입니다. 이 순서는 의도한 첫 메시지와 맞습니다. |
| 새 관찰자(AI) 관찰 | `not_run`: 별도 관찰자가 없었습니다. |
| 사람 대상 3초 관찰 | `not_run`: 참가자가 없었습니다. |

이 결과만으로 "3초 테스트 통과"라고 말할 수는 없습니다. 예측과 의도가 어긋난 점은 찾지 못했습니다.

## 3. 개선 제안 (승인된 방향 안에서)

**심각도를 매길 지적 사항은 없습니다.** 비대칭, 오른쪽 빈 공간, 회전된 표제는 승인된 정체성이므로 정리하거나 맞추지 않습니다. CTA도 추가하지 않습니다.

아래 두 가지는 확인이 필요한 사항입니다. 실제 문제가 관찰된 것은 아닙니다.

- **링크가 지나치게 약하게 보일 가능성:** 진입점 두 개가 18px 기본 링크로 맨 아래에 있습니다. 스크린샷 기준으로 첫 화면 안에는 보입니다. 다만 관찰 결과가 "탐색 진입점을 알아보지 못함"으로 나올 때만 바꾸는 게 맞습니다. 그 경우에도 세리프나 벽돌색처럼 기존 시각 언어 안에서 강조를 조정합니다. 버튼이나 카드로 바꾸지는 않습니다.
- **색면이 작품으로 읽히는지:** 색면 3개에는 제목이나 대체 텍스트가 없습니다. 이 색면이 작품 자리인지 장식인지는 의도가 `unknown`입니다. 콘텐츠 결정이 필요하니 상위 담당자에게 넘깁니다.

## 4. 근거와 확인 한계

- **링크 대상 없음:** `#works`, `#artist`가 가리키는 대상이 소스에 없습니다 (`index.html:2`). 브리프가 "이 상태만 구현"이라고 하므로 결함이 아니라 아직 남은 작업으로 기록합니다. 클릭해서 실패하는 것을 관찰한 것도 아닙니다.
- **확인하지 못한 항목:** 다음은 모두 `Not verified`입니다.
  - 320px 너비와 200% 확대에서 회전된 표제가 잘리는지
  - 키보드 포커스 표시가 실제로 어떻게 보이는지
  - 좁은 화면에서 링크가 첫 화면 밖으로 밀려나는지
- **결과 단계:** 렌더링은 스크린샷으로만 봤습니다. 동작 확인과 사용자 수용은 모두 `not_run`입니다. 확정된 범위는 위 명세의 구조와 순서까지이고, 나머지 두 항목은 결정이 필요합니다.

**판정:** Approve. 정적 확인 범위 안에서 차단할 문제는 없습니다. 위의 확인 한계는 그대로 남아 있습니다.
