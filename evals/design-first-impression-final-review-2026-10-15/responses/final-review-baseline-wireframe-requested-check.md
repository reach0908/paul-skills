# S06 / gallery / r1: 화면 명세와 첫인상 검토

## 화면 명세
| 항목 | 내용 |
|---|---|
| 대상 | `index.html`, state `gallery`, revision `r1`, 캡처 1040×800 (`capture.json`, `screen.png`) |
| 목적 | 작품과 탐색 진입점을 알리는 갤러리 (`BRIEF.md:1`) |
| 첫 메시지 | 「불완전한 종이의 풍경」은 ORBIT의 작은 전시 014이자 종이 조각을 모은 디지털 작품집이라는 것 |

| 보존할 것 | 노란 히어로의 −1° 기울기, 세리프 제목, 벽돌색·남색·베이지 조각 패널, 비대칭 여백, 두 탐색 링크, 키보드 포커스 표시(`outline 3px #1849be`) |

| mock 경계 | `#works`, `#artist`의 이동 대상 요소가 소스에 없음. 브리프에 "Only the supplied state is implemented"라고 되어 있으므로 결함이 아니라 아직 구현하지 않은 목적지로 봄 |

## 첫인상 3초 검토
| 방법 | 상태 |
|---|---|
| 사람 대상 3초 관찰 | `not_run`: 참가자가 없음 |
| 새 맥락 AI 관찰 | `not_run`: 추가 참가자를 쓸 수 없음 |
| 작성자 사전 점검 | 실시함. 시간 측정 없음. 저는 브리프의 의도를 이미 알고 있었음 |

**사전 점검 예측:** 가장 먼저 보이는 것은 노란 히어로 안의 큰 세리프 제목일 것입니다. 이어서 작품집이라는 한 줄 소개와 색 조각이 눈에 들어올 것으로 예상합니다. 두 링크는 800px 높이 안의 약 y=670에 있어 첫 화면에 들어옵니다. 다만 작은 본문 크기의 밑줄 링크라서 시각적 무게는 가장 낮습니다.

**의도와 비교:** 전시명과 작품집이라는 성격은 의도대로 전달될 것으로 예상합니다. 진입점은 보이지만 존재감이 약합니다. 이 판단은 예측이고 실제로 관찰한 불일치가 아닙니다. 따라서 "3초 테스트 통과"라고 말할 수 없습니다.

## 개선 제안
근거가 확인된 차단 문제는 **없습니다.** 비대칭, 오른쪽 빈 공간, 콜라주 기울기는 승인된 정체성이라 정규화 대상이 아닙니다. CTA나 카드형 UI는 추가하지 않습니다.

아래 두 가지는 관찰로 확인되지 않은 위험이라 검증 노트로만 둡니다.
1. **조각이 작품으로 읽힐지 여부.** 세 조각은 이름 없는 `div`라서 보조기기에서는 작품이 전달되지 않습니다(소스 사실). 시각적으로도 장식인지 작품인지 판단할 근거가 없습니다. 실제 작품 이미지를 넣을 때 `alt`나 작품명을 함께 넣을지는 build-design과 accessibility 담당이 확인하면 됩니다.
2. **좁은 화면의 제목 크기.** 인라인 64px 때문에 600px 이하에서도 `h1` 축소가 적용되지 않습니다(소스 사실). 줄바꿈이 어색해지는지는 렌더링해 봐야 알 수 있어 확인 대기입니다.

탐색 링크를 더 강조하는 것은 실제 관찰에서 진입점을 놓친다는 결과가 나올 때만 검토하는 편이 맞습니다.

## 확인 한계
- 브라우저를 쓸 수 없었습니다. 그래서 링크 클릭, 키보드 이동, 좁은 화면 레이아웃은 확인하지 못했습니다. 근거는 `screen.png` 한 장(1040×800)과 소스뿐입니다.
- 결과 단계를 나누면, 렌더링은 r1 캡처로만 확인했고, 동작 확인과 사용자 수용은 모두 `not_run`입니다.
- 파일은 수정하지 않았습니다.
