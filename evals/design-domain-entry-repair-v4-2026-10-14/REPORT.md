# 분야별 선행 로드와 문서 읽기 수정 검증

**정식 배포 보류.** Codex 27/27, Claude 26/27입니다. 두 호스트의 호출·로드·범위 검사는 모두 통과했으나, Claude의 마지막 색상 답변이 입력란 안내 문구의 대비 기준을 잘못 설명하여 의미 판정에서 실패했습니다. [다음 보완](../design-contrast-boundary-repair-2026-10-14/REPORT.md)에서 이 참조 문구를 수정하고 영향받는 시험을 재검증합니다.

## 수정한 동작

Codex의 실제 자동 발견 목록에서 스킬 설명이 약 80자로 줄어드는 것을 확인했습니다. 여섯 분야 스킬의 첫 문장에 직접적인 변경·회귀 리뷰 제외 조건과 정식 전달 후 참여 조건을 함께 넣었습니다. 글꼴이나 색상을 명시한 staged 리뷰도 `better-interface`만 먼저 읽고 명시 호출 명령을 안내합니다. 현재 화면 점검과 수정 요청은 각 분야로 직접 진입할 수 있습니다.

정식 변경 리뷰가 시작되면 여섯 분야의 원문을 모두 읽은 뒤 근거가 있는 범위를 판단합니다. 한 속성만 바뀌었거나 접근성 문제 하나를 발견했다는 이유로 다른 분야의 원문을 생략하지 않도록 실행 절차를 보완했습니다. 각 분야의 기존 판단 규칙은 유지했습니다.

색상 참조 문서는 설치 위치에서 실제 경로를 해석하고, 각 읽기의 성공 여부와 전체 내용을 확인하도록 했습니다. JavaScript 반복문의 변수를 셸 위치 인자처럼 사용하던 잘못된 명령을 피하도록 안내합니다. Claude가 호출 인자로 치환하는 번호형 달러 표기 역시 설명문에서 제거했습니다.

## 시험 구성

각 호스트에서 독립된 새 CLI 세션 27개를 사용합니다. 후보는 일상 설치와 분리된 임시 플러그인으로 설치했고, 원본 스킬·문제·시험 절차의 해시를 실행 전에 고정했습니다. 같은 후보의 답을 재시도하거나 실패를 삭제하지 않았습니다.

| 시험 | 호스트별 개수 | 확인하는 동작 |
| --- | --- | --- |
| 자동·명시 진입 경계 | 11 | staged·working·branch 안내, 분야명 포함 요청, 분야별 선행 로드 방지 |
| 일반 호출 | 10 | 여섯 분야, 색상 반복 2회, 현재 화면 종합 검토, IA |
| 명시 working 준비 | 3 | HEAD 기준, 이전 커밋 제외, untracked 포함, 미검증 결과 구분 |
| 실제 리뷰 전달 | 3 | 일반 working, index와 작업 트리가 다른 staged·working |

실제 리뷰용 저장소는 main보다 HEAD가 앞서도록 만들었습니다. HEAD에는 버튼 이름이 있고 index에서는 제거했으며, 별도 사례의 작업 트리에서는 복원했습니다. staged는 index의 회귀를 찾고 untracked 파일을 제외해야 합니다. working은 상쇄된 기존 파일을 제외하고 새 untracked 파일의 결함을 찾아야 합니다. 여섯 분야의 완전한 원문 로드, 실제 Git 조회, 최종 답변의 범위를 함께 판정합니다.

## 증거와 검증 기준

- 각 응답은 [Codex](codex/summary.json)와 [Claude](claude/summary.json) 요약 및 개별 증거 파일에 남습니다. 최종 답변의 수동 의미 판정은 [해시가 연결된 판정 기록](manual-review.json)에 저장합니다.
- 스킬 이름을 언급했다는 사실만으로 로드 성공으로 보지 않습니다. 설치 원문과 전체 내용의 일치, 실행 경로, 네이티브 호출 식별자를 확인합니다.
- 선택 문서가 없어서 검색이나 존재 확인이 1을 반환한 사례는 실제 읽기 오류와 구분합니다. 변경하지 않은 저장소의 목록과 제한된 읽기 전용 재현으로 예상된 종료임을 확인하고, 연결된 명령 중 실행되지 않은 부분에는 점수를 주지 않습니다. [판정기 보완과 제한](GRADER-NOTES.md)에 근거를 남겼습니다.
- 원본 0.4.1의 여섯 분야 규칙 본문은 새 진입·읽기 안내를 제외하면 같습니다. 기존 종합 리뷰 절차는 유지하고 여섯 분야를 모두 읽으라는 문단만 추가했습니다. 불변 원본 리비전은 바꾸지 않았습니다.

54개 새 세션을 모두 완료했습니다. 호출 경계 11개, working 준비 3개, 실제 전달 3개는 양쪽 모두 통과했습니다. 일반 호출 10개는 Codex 10/10, Claude 9/10입니다. 색상 참조 원문 읽기는 Codex 18회, Claude 15회 성공했고 읽기 오류는 없었습니다. [참조 읽기 증거](reference-reads.json).

실패 답변은 [normal-better-colors-3](claude/normal-better-colors-3.json)에 보존했습니다. WCAG 중심 측정표에서 비활성 텍스트와 placeholder를 함께 면제했습니다. [W3C SC 1.4.3 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)은 placeholder에도 텍스트 대비 기준이 적용된다고 명시합니다. 기존 `contrast.md`의 APCA 문장을 기준 구분 없이 재사용한 것이 가능한 원인입니다. 이는 원인 추정이며, 호출이나 읽기 실패는 아닙니다.

패키지 검사 38개, 판정기 검증 26개, 엄격한 플러그인 검증과 공백 검사를 통과했습니다. [검증 기록](validation.json). 임시 후보 175개 파일과 일상 설치의 호스트별 174개 파일을 확인했습니다. Claude의 표시 비용은 USD 14.0004654이며 실제 청구액은 확인할 수 없습니다. Codex 비용은 환산하지 않았습니다. 이번 요청의 후보 5부터 8까지 총 132개 독립 세션을 보존했습니다.

`python3 evals/design-domain-entry-repair-v4-2026-10-14/verify_evidence.py`로 증거 무결성을 확인할 수 있습니다. 무결성 통과가 의미 판정 실패를 합격으로 바꾸지는 않습니다.

## 해석의 한계

이번 검증은 알려진 실패를 보완하는 반복 시험이며, 독립된 미공개 문제를 사용한 신뢰도 추정이 아닙니다. 의미 판정은 작업을 수행한 유지보수 에이전트가 했고 독립 블라인드 심사는 아닙니다. Codex CLI 0.146.0의 gpt-5.6-sol/medium, Claude Code 2.1.296의 claude-opus-5-5/xhigh에서 확인합니다. 다른 모델이나 데스크톱 경로 전체에 일반화하지 않습니다.

호출·읽기·범위의 합격은 17개 디자인 역할 전체가 원본보다 뛰어나다는 새 증거가 아닙니다. 이번에는 실제 제품의 렌더링 QA나 시각 품질 비교를 수행하지 않았습니다. 일상 Codex·Claude 전역 설치는 0.4.1을 유지하며, 이번 후보의 게시·배포·전역 설치는 수행하지 않습니다.
