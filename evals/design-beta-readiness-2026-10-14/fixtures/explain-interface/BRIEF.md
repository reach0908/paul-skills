# 공유 자료함, 결정본 PB-72 revision 3
사용자는 팀의 읽기 목록에서 자료를 찾아 내 보관함에 저장한다. 제품 기획은 완료됐다. 화면 전체를 다시 기획하지 않는다.
현재 목적지 D-LIB(자료함 /library), D-ITEM(자료 상세 /items/:id), D-SAVED(내 보관함 /saved), D-HELP(도움말 /help)를 유지한다. 태그와 작성자는 필터이며 새 전역 메뉴가 아니다. 자료의 ID는 목록·검색·추천에서 동일하다. 좁은 화면에서도 검색과 내 보관함은 접근 가능해야 한다.
콘텐츠: 제목, 요약, 작성자, 태그, 원문 URL. 아이템 R-72의 제목은 '작은 팀에서 실패 후 다시 시도하기'. 본문 내 출처 링크는 원문 URL이고 자료 목록으로 이동하는 링크가 아니다.
자료 상세의 저장 작업은 T-SAVE다. 메모 초안을 입력하고 저장할 수 있다. 저장 요청은 pending 표시 후 서버 확인(유일 receipt S-72)에서만 성공이다. 첫 요청은 timeout-unknown: 서버 처리 여부가 알려지지 않으므로 실패·성공으로 단정하지 않는다. 승인된 복구는 상태 확인이며 새 저장 요청 재전송이 아니다. 상태 확인 첫 결과는 pending, 두 번째는 succeeded. 닫기는 진행 작업을 서버 취소하지 않으며 초안은 유지한다. 같은 요청의 중복 입력은 무시한다. 인증 복구 후 동일 키로 작업을 재조회하는 서버 API는 아직 미정이다. 이 지점은 미결로 표시한다.
기존 뒤로가기 문맥은 검색어 q='작은 팀', tag='운영', 정렬 newest, 목록 위치 item R-72를 유지한다. 상세 안의 '출처로 이동' 및 '본문으로 건너뛰기'는 현재 자료와 입력을 바꾸지 않는다. 새 권한 정책은 결정하지 않는다: 초대가 만료된 팀 자료를 읽을 수 있는지 아직 미정이다. 보관함의 내 메모와 타인의 원문은 같은 소유권 정책이 아니다.
