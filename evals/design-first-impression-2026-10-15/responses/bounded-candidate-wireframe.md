# F01 좌석 예약 화면 명세 (와이어프레임, 구현 없음)

**입력:** `BRIEF.md` (B01, F01, S01–S03). 파일은 수정하지 않았습니다.
**상태:** 명세 초안이 정리된 단계입니다. 화면을 렌더링하지 않았고, 동작 확인과 사용자 수용 확인도 하지 않았습니다.

## 흐름 매핑
| 흐름 단계 | 화면/상태 |
|---|---|
| 날짜 선택 | S01 |
| 좌석 선택 | S02 |
| 확인·확정 | S03 |
| 예약 실패 | S03-E (S03 안에서 보여 주는 상태) |
| 예약 성공 | S03-OK (이름은 임시이며, 브리프에는 성공 화면 정의가 없음) |

**범위 밖:** 유료 결제, 가입 유도

## S01 날짜 선택
- **목적·첫 메시지:** "이용할 날짜를 고르세요. 운영시간과 휴관일을 여기서 확인할 수 있습니다."
- **정보 위계:**
  1. 단계 표시 (1/3)
  2. 날짜 선택기
  3. 선택한 날짜의 운영시간
  4. 휴관일 안내
- **주 행동:** 날짜 선택 후 "좌석 선택"으로 이동
- **상태:**
  - 기본: 날짜가 선택되지 않아 다음 단계로 갈 수 없음
  - 휴관일: 선택할 수 없고, 이유를 글로 안내 (색에만 의존하지 않음)
  - 운영일 선택됨: 운영시간을 보여 주고 다음 단계 활성화
- **모바일:** 운영시간 안내를 날짜 선택기 바로 아래에 둡니다. 다음 버튼은 화면 아래에서 항상 닿을 수 있게 합니다.

## S02 좌석 선택
- **첫 메시지:** "[선택한 날짜]에 이용할 수 있는 좌석을 고르세요."
- **정보 위계:**
  1. 선택한 날짜 요약과 변경 링크 (S01로 이동)
  2. 범례: 사용 가능 / 사용 중 / 휠체어 접근
  3. 좌석 목록 또는 배치도
  4. 선택한 좌석 요약
- **주 행동:** "확인으로"
- **보조 행동:**
  - 선택 해제
  - 이전 단계
  - 휠체어 접근 좌석만 보기 (제안이며, 브리프는 좌석 표시만 요구함)
- **상태:**
  - 미선택: 다음 단계 비활성
  - 선택됨: 좌석 요약 표시
  - 사용 중 좌석: 선택할 수 없고, 상태를 글로 표시
  - 가능 좌석 없음: 날짜 변경을 안내
- **접근성:** 배치도와 별도로 목록·키보드로 선택할 수 있게 합니다. 휠체어 접근 여부는 아이콘과 함께 텍스트 레이블을 붙입니다.
- **모바일:** 목록을 먼저 보여 주고 배치도는 접어 둡니다. 선택 요약과 다음 버튼은 화면 아래에 고정합니다.

## S03 확인
- **첫 메시지:** "아래 내용으로 예약을 확정합니다."
- **정보 위계:**
  1. 날짜
  2. 좌석 (휠체어 접근 여부 포함)
  3. 이용 시간
  4. 취소 규정
  5. 확정 버튼
- **주 행동:** "예약 확정"
- **보조 행동:** 날짜 변경, 좌석 변경. 둘 다 지금 선택을 유지한 채 해당 단계로 돌아갑니다.
- **상태:**
  - 제출 중: 버튼 비활성, 진행 중 표시
  - S03-E 실패: 선택은 그대로 두고 오류 메시지를 보여 줍니다. 선택지는 "다시 시도"와 "이전 단계(좌석 선택)" 두 가지입니다.
  - S03-OK 성공: 예약 요약을 보여 줍니다. 다음 행동은 미정입니다.

## 미결정 사항 (해당 화면 동작을 막는 것)
1. **예약 유지 시간:** S02나 S03에 남은 시간 표시나 만료 상태가 필요한지 결정할 수 없습니다. 이 부분은 비워 두었습니다.
2. **이용 시간을 고르는 위치:** S03에 이용 시간을 보여 줘야 하지만, 어디서 고르는지 브리프에 없습니다. 고정 시간일 수도 있고 S01이나 S02에서 고를 수도 있습니다.
3. **취소 규정 문구와 출처:** 브리프에 내용이 없습니다.
4. **성공 화면의 내용과 다음 행동:** 정의되지 않았습니다.
5. **실패 원인별 분기:** 좌석이 그 사이 예약된 경우를 다르게 처리할지 정해지지 않았습니다. 그런 경우 "이전 단계"를 기본으로 권할지도 함께 정해야 합니다.

## 근거와 확인 한계
- **근거:** 모든 화면 요소는 BRIEF.md의 S01–S03 요구, 실패 시 선택 보존 규칙, 범위 밖 항목에서 가져왔습니다. 브리프에 없는 내용은 "제안" 또는 "미정"으로 표시했습니다.
- **한계:**
  - 브라우저를 쓸 수 없어서 렌더링, 키보드 조작, 화면 폭별 배치를 확인하지 못했습니다.
  - 참가자가 없어서 처음 볼 때 메시지가 잘 전달되는지는 확인하지 않았습니다. 위의 첫 메시지는 의도일 뿐 관찰 결과가 아닙니다.
  - 브리프에 IA나 기존 제품 맥락이 없어서 실제 내용 길이와 경로는 정하지 않았습니다.
