user-flow로 내보내기 패널의 전이 계약을 `outputs/user-flow.md`에 만들어줘. 화면 디자인과 구현은 하지 마. 아래 정책과 destination ID를 보존하고, 정책이 미정인 부분은 미정으로 표시해줘.

정책:

- actor는 로그인한 편집자다. 진입 destination은 `exports-panel`, 복귀할 부모는 `documents-list`다.
- 처음에는 옵션만 있고 request key와 receipt는 없다.
- 시작하면 새 request key를 만든다. 진행 중에 시작을 다시 누르면 같은 요청으로 처리한다.
- 실패하면 옵션과 key를 보존하고, 재시도에는 같은 key를 쓴다.
- 서버가 완료를 확인한 뒤에만 receipt와 다운로드가 생긴다.
- 패널 닫기는 미시작, 진행, 실패, 완료 상태에서 모두 가능하며 요청을 취소하지 않는다.
- 같은 세션에서 다시 열면 해당 작업의 상태와 데이터를 복원한다. 닫혀 있는 동안 서버가 완료하면 다시 열었을 때 완료 상태다.
- 새로고침 이후의 복원 정책은 아직 정하지 않았다.
- 취소 기능은 이번 범위에 없다.
