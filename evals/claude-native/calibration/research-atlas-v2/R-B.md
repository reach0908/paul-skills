# Atlas Import v2: CSV 지원과 최대 업로드 용량

- 조사일: 2026-10-16
- 범위: `sources/`에 제공된 자료만 사용했다. 네트워크 자료는 열지 않았다.

## 결론

- v2는 CSV 파일을 지원하며, 최대 업로드 용량은 20 MB다 [D1].
- 5 MB는 v1의 제한이며 v2에서 상향됐다 [D2, D4].
- 실측 속도는 이 자료로 알 수 없다. 제공된 자료에 속도 측정값이 없다.

## 근거

- D1: Atlas Import v2 매뉴얼
- D2: Atlas Import v1 매뉴얼
- D4: Atlas Import v2 릴리스 노트

## 상충 자료

D3 블로그의 5 MB 주장은 버전이 없어 v2 제한의 근거로 쓰지 않았다.

## 한계
