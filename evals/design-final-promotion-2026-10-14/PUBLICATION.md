# 공개 승인 대상

대상은 기존 공개 저장소 `reach0908/paul-skills`다. GitHub PR과 병합을 거쳐 0.4.0 태그를 발행하고, 자체 marketplace에서 두 호스트의 사용자 범위 설치를 갱신하는 작업이다. npm 패키지 발행은 없다.

포함할 자료:

- 새 정식 스킬 8개, 관련 docs·목록·라우터·출처·Changeset.
- 이전 베타 재비교와 보완 보고서, 입력 fixture, 실행 산출물, 측정·해시·호출 증거.
- 로컬 시험 화면 PNG 125개. 이전 검증 기록을 그대로 보존하기 때문에 같은 이미지가 여러 경로에 있을 수 있다.
- 이번 승격·시험 설치·발견 결과와 공개 후 릴리스·설치 영수증.

현재 검토 후보는 약 20.5 MB다. 파일별 경로·크기·해시는 로컬 `.scratch/design-final-promotion-20261014/publication-manifest.json`에 보관한다. 마지막 릴리스 영수증은 실행 후 추가된다.

제외할 자료는 `.scratch/` 원시 호스트 로그, 임시 인증 연결, 개인 설정, 기존 `.playwright-cli/` 작업이다. 평가 텍스트에서 개인키·GitHub/OpenAI 토큰·인증 payload 패턴은 발견되지 않았다. 이는 모든 민감 정보가 없다는 보증은 아니며, 캡처와 실행 산출물이 공개 대상이라는 점을 포함해 승인한다.

사용자가 구체적인 공개 범위 질문에 “공개 및 배포 승인”으로 답했다. 평가 자료·캡처를 포함한 공개 게시, PR 병합, 0.4.0 발행과 Codex·Claude 전역 설치 갱신을 승인했다. 초기 자동 승인 차단은 기록으로 보존하며, 실제 완료 상태는 REPORT.md에 갱신한다.

공개 실행 결과: 승격 PR #14와 버전 PR #15가 병합됐고 `paul-skills@0.4.0`이 발행됐다. 두 호스트의 사용자 범위 설치를 갱신하고 파일 동일성·새 Codex 카탈로그·전역 호출 검사 9/9를 확인했다. 상세 영수증은 [보고서](REPORT.md)에 연결했다.
