# Meeting notes preview

This is a local Korean preview. It uses system fonts and plain borders. Team members can read a single note, Studio 회의록. Search filters the accessible notes. The membership-update control simulates loss of access; it does not delete the note or affect an external account. After the update, changing a query cannot restore permission. The help control always explains how to ask the team administrator for access. There is no automatic access request, confirmation of restored access or sign-in flow. Keep those policy decisions and the mock boundary intact.
