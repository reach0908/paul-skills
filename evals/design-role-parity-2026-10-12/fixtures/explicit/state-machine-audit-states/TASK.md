# state-machine: audit-states

활동 기록 컴포넌트 components/audit-log.js의 현재 가능한 상태를 볼 수 있는 임시 작업 페이지를 만들어 주세요. 경로는 workbench/audit/index.html로 해 주세요. 실제 컴포넌트를 사용하고 제품 화면이나 컴포넌트 모양은 바꾸지 마세요. 상태를 한 번에 하나씩 선택하고 링크로 공유할 수 있으면 돼요. 시연 후에도 페이지를 남겨 주세요.

결과는 한국어로 작성하고 실제로 만든 파일, 확인한 경로와 상태, 관찰 근거, 확인하지 못한 내용을 구분해 주세요. 이 과제에 필요한 로컬 파일과 정적 서버만 사용하세요. 실제 서비스 호출이나 패키지 설치는 필요하지 않아요.
