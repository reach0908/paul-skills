# interface-review: change-causes

공유 링크 도구를 다듬은 현재 변경을 리뷰해 주세요. 대상 인자는 따로 지정하지 않을게요. 새 버전은 같은 작업을 더 간단하게 제공하는 게 목적이에요. 변경으로 생긴 인터페이스 문제를 찾아 한국어 리뷰를 작성해 주세요. 코드를 고치지는 마세요. 저장소는 준비 스크립트가 만든 로컬 Git 저장소이고 원격 통신은 필요하지 않아요.

결과는 한국어로 작성하고 실제로 만든 파일, 확인한 경로와 상태, 관찰 근거, 확인하지 못한 내용을 구분해 주세요. 이 과제에 필요한 로컬 파일과 정적 서버만 사용하세요. 실제 서비스 호출이나 패키지 설치는 필요하지 않아요.
