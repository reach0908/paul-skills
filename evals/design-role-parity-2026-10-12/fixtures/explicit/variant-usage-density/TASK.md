# variant: usage-density

작업실 index.html의 전송량 카드 하나에 대해 밀도가 다른 세 가지 안을 실제로 만들어 주세요. 다른 패널은 유지하고 742 GB 사용량, 초기화 날짜, 팀원 수와 요금제 확인 동작은 모든 안에 남겨 주세요. 실제 페이지에서 한 번에 하나씩 바꿔 볼 수 있게 해 주세요. 아직 고르지는 않을 테니 비교 화면과 각 안의 장단점을 남겨 주세요.

결과는 한국어로 작성하고 실제로 만든 파일, 확인한 경로와 상태, 관찰 근거, 확인하지 못한 내용을 구분해 주세요. 이 과제에 필요한 로컬 파일과 정적 서버만 사용하세요. 실제 서비스 호출이나 패키지 설치는 필요하지 않아요.
