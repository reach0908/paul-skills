# explain-interface: runtime-reveal

로컬 페이지의 두 줄 제목이 나타나는 움직임만 분석해 주세요. 다시 재생 버튼을 눌러 시작 순간도 볼 수 있어요. 어느 순서로 무엇이 움직이는지, 속도감이 생기는 이유를 실제 관찰과 근거로 설명해 주세요. 구현 코드 복제나 사이트 전반의 리뷰는 필요하지 않아요. 폼 제출은 요청하지 않았어요.

결과는 한국어로 작성하고 실제로 만든 파일, 확인한 경로와 상태, 관찰 근거, 확인하지 못한 내용을 구분해 주세요. 이 과제에 필요한 로컬 파일과 정적 서버만 사용하세요. 실제 서비스 호출이나 패키지 설치는 필요하지 않아요.
