# state-machine: remove-workbench

활동 기록의 상태 확인을 끝냈어요. workbench/audit에 만든 임시 상태 페이지와 fixture만 제거해 주세요. 제품 활동 기록과 docs/state-policy.md는 유지해야 해요. 임시 파일이나 import가 남지 않았는지 확인하고 한국어로 결과를 알려 주세요.

결과는 한국어로 작성하고 실제로 만든 파일, 확인한 경로와 상태, 관찰 근거, 확인하지 못한 내용을 구분해 주세요. 이 과제에 필요한 로컬 파일과 정적 서버만 사용하세요. 실제 서비스 호출이나 패키지 설치는 필요하지 않아요.
