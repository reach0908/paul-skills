# Studio Desk local preview

This is a small internal collaboration tool. Korean is the interface language; product names, project names and identifiers retain their original English spelling. Use the current system font stack and semantic CSS variables. The warm neutral palette, simple borders, compact tables and absence of shadows are deliberate.

Supported viewport widths: 320, 768 and 1280 CSS pixels. Test any exposed state controls locally. All effects live in this page's memory and reset on reload. There are no accounts, network submissions, analytics, external images or live services. The accessibility target is WCAG 2.2 AA. Plain punctuation and sentence case are established policy. Do not replace the product's terms or visual identity based on taste.

The translation table is used by professional reviewers. Its deliberate body role is .875rem with 1.5 to 1.6 unitless line height; inputs stay at 1rem. All text remains selectable.
