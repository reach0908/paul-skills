## Verification

- **Calculated pairs:** I worked out the contrast values by hand with the WCAG relative-luminance formula: `#ffffff`/`#2563eb` = 5.17:1, `#ffffff`/`#60a5fa` = 2.54:1, `#111827` against each accent 3.37 → 6.85:1. The sandbox blocked a script-based calculation.
- **Layout arithmetic:** the overflow is computed from the declared fixed track widths, padding and `max-width`.
- **Not verified:** rendered contrast, the actual overflow and scrolling at 320px and 200% zoom, translated label lengths, keyboard and screen-reader walkthroughs. No browser verification was requested, so none was run.
