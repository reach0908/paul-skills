- **소스 기반 계산:** WCAG relative luminance 공식으로 대비를 직접 계산했습니다. 결과는 `#fff`/`#2563eb` 5.17:1, `#fff`/`#60a5fa` 2.54:1입니다. 스크립트로 다시 계산하려던 명령은 이 세션의 Bash 권한이 막혀 실행하지 못했습니다.
- **소스 기반 계산:** 툴바 폭 880px와 컨테이너 폭 720px는 CSS 값으로 계산했습니다. 고정 px 트랙이라 줄어들 수 없습니다.
- **Not verified:** 렌더링된 화면에서의 대비, 320px 폭과 200% 줌에서의 실제 넘침, 키보드와 스크린 리더 동작. 요청대로 브라우저 검증은 하지 않았습니다.
