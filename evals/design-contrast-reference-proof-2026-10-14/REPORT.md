# 디자인 호출·문서 읽기 패치의 최종 배포 판단

**정식 패치 배포 가능으로 판단합니다.** Codex의 분야별 선행 로드와 문서 읽기 명령 문제를 해결했고, Claude의 기존 호출·전달 흐름도 유지했습니다. 검증 중 발견한 색상 기준 혼동까지 수정했습니다. 이 판단은 아래 CLI·모델·작업 범위에 한정되며 아직 게시·배포·전역 설치는 하지 않았습니다.

## 수정 내용

1. 여섯 분야의 짧은 자동 발견 설명에 직접 변경 리뷰 제외와 정식 전달 후 참여 조건을 함께 넣었습니다. 변경 리뷰는 `better-interface`부터 시작하고 명시 호출을 안내합니다. 현재 화면 점검과 수정 요청은 분야 스킬로 직접 들어갑니다.
2. 실제 리뷰 전달에서는 여섯 분야 원문을 모두 읽은 뒤 적용할 근거가 있는지 판단합니다. 발견 하나나 작은 변경을 이유로 다른 분야를 생략하지 않습니다.
3. 색상 참조 문서는 실제 설치 경로를 넣어 읽고 각 결과를 확인합니다. JavaScript 변수와 셸 위치 인자를 혼동하는 명령, Claude 호출 인자로 치환되는 설명을 제거했습니다.
4. 활성 입력란의 placeholder와 읽기 전용 문구의 WCAG 기준을 비활성 컨트롤 면제 및 APCA 목표와 분리했습니다. [W3C SC 1.4.3 설명](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)에 근거했습니다.

HEAD 대비 working 순변경과 untracked 포함, HEAD 대 index의 staged 범위도 재검증했습니다. 원본 분야 규칙은 진입·읽기 안내를 제외하면 유지했고, 추가로 변경한 내용 규칙은 색상 참조의 기준 구분 한 곳입니다. 원본 리비전은 유지했으며 출처 기록·사용 문서·Changeset을 맞췄습니다.

## 어떤 결과를 다시 실행했는가

직전 후보의 전체 새 세션 결과는 Codex 27/27, Claude 26/27입니다. 호출·문서 읽기·범위는 모두 통과했으나 Claude의 색상 답변 한 건이 placeholder를 면제 대상으로 설명해 의미 판정에서 실패했습니다. [당시 결과와 실패 원문](../design-domain-entry-repair-v4-2026-10-14/REPORT.md)은 그대로 보존했습니다.

그 후 설치 파일 175개 중 `better-colors/contrast.md` 하나만 바꿨습니다. 모든 진입 설명·SKILL 본문·전달 절차 등 174개는 직전 후보와 같습니다. 실제 호출 및 문서 출력 기록을 조사하여 해당 참조를 읽지 않은 통과 사례 48개를 선행 증거로 재사용했습니다. 참조를 읽었던 색상 과제 6개는 같은 문제로 새 세션에서 다시 실행하여 모두 통과했습니다. [변경 범위와 의존성 증거](../design-contrast-boundary-repair-2026-10-14/impact-analysis.json).

새 색상 답변 중 일부는 참조를 읽지 않았기 때문에, 올바른 답만으로 원문 수정 적용을 주장하지 않았습니다. 추가로 설치된 대비 문서를 직접 읽는 명시 호출을 두 호스트에서 각각 2개씩 실행했고 **4/4 통과**했습니다. 모두 완전한 스킬 본문과 수정한 `contrast.md`를 읽은 증거가 있습니다. [원문 읽기 기록](reference-reads.json), [응답별 의미 판정](manual-review.json).

| 확인한 경로 | Codex | Claude | 실행 구분 |
| --- | --- | --- | --- |
| 자동·명시 변경 리뷰 진입 경계 | 11/11 | 11/11 | 변경 없는 선행 증거 |
| 색상을 제외한 일반 호출·현재 화면 검토·IA | 7/7 | 7/7 | 변경 없는 선행 증거 |

이는 기존 54개 작업 흐름을 변경 없는 48개와 재실행한 6개로 검증하고, 명시 참조 확인 4개를 추가한 결과입니다. 최종 소스로 전체 54개를 새로 실행했다고 해석하면 안 됩니다.

## 남겨 둔 실패와 판정의 경계

별도의 일반적인 대비 기준 질문에서 Claude는 스킬을 사용하지 않고 올바른 답을 했습니다. 이 질문이 반드시 색상 스킬을 부를 것이라는 시험 기대는 충족되지 않았고, [추가 자동 질문의 0/1](../design-contrast-boundary-repair-2026-10-14/claude/normal-better-colors-thresholds.json)을 유지했습니다. 스킬 적용 성공으로 재채점하지 않았습니다.

일반 지식 질문의 모든 답변에 스킬 사용을 강제하는 것은 이번 배포 보장의 범위가 아닙니다. 기존 색상 작업의 자동 진입은 3회씩 유지됐고, 명시 호출·원문 적용은 별도로 통과했습니다. 따라서 이 자동 질문의 미호출을 원문 읽기 성공 증거에서 제외하되, 기존 작업 흐름의 회귀로 판단하지 않았습니다. 모든 기준 질문의 강제 자동 호출이 별도 요구사항이 되면 추가 작업이 필요합니다.
