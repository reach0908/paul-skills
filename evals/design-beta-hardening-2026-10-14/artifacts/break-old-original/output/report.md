# `renderQueueCard` 스트레스 관찰 보고서

대상은 큐 항목 데이터와 표시 상태를 받아 제목과 반복 목록을 렌더링하는 `app/queue.js`의 `renderQueueCard`입니다. 실제 함수를 `app/stress/`에서 import했으며 제품 파일은 변경하지 않았습니다.

## 적용한 시나리오

- 제목: 빈 문자열, 한 단어, 일반 제목, 여러 문장, 끊기지 않는 긴 문자열
- 목록 수량: 0개, 1개, 현실적 수량 5개, 현실적 수량의 10배인 50개
- 좁은 컨테이너: 320px, flex 형제에 눌린 폭
- 코드 상태: 권한 없음, 로딩, 오류, 기존 목록을 유지한 새로고침, 검토 잠금

넓은 컨테이너, 문자 형태(이모지·RTL·혼합 방향·발음 구별 기호), 테마, 확대, 모션은 사용자 지정 범위 밖이라 제외했습니다. 빈 목록은 수량 축에서 한 번만 다뤘습니다.

## 관찰 결과

| 시나리오 | 실제로 보인 현상 | 담당 |
| --- | --- | --- |
| 제목 — 빈 문자열 | 제목 글자 없이 빈 버튼만 표시됨 | `better-writing` |
| 제목 — 여러 문장 | 한 줄 버튼이 카드의 오른쪽 테두리를 넘어감 | `better-typography` |
| 제목 — 끊기지 않는 긴 문자열 | 줄바꿈이나 말줄임 없이 버튼이 카드의 오른쪽 테두리를 넘어감 | `better-typography` |
| 좁은 컨테이너 — flex 형제에 눌린 폭 | 제목이 글자 단위로 세로로 갈라지고 버튼이 좁은 카드의 오른쪽 경계를 넘어감 | `better-layout` |

0·1·5·50개 수량, 320px 컨테이너, 권한 없음·로딩·오류·새로고침·잠금 상태에서는 겹침이나 경계 이탈이 보이지 않았습니다.
