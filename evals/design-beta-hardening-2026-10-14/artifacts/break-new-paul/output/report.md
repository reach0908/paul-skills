# 첨부 파일 컴포넌트 스트레스 관찰

대상은 파일명 목록과 `loading`, `readOnly`, `wrapNames` 상태를 받아 첨부 파일 섹션을 렌더링하는 `renderAttachments`입니다.

## 포함한 시나리오

- 내용 길이: 빈 문자열, 한 단어, 대표 파일명, 여러 구절, 줄바꿈 없는 최대 220자
- 내용 형태: 이모지 혼합, RTL/LTR 혼합, 발음 구별 부호와 큰 문자
- 수량: 0개, 1개, 현실적 수량 3개, 스트레스 수량 30개
- 컨테이너: 제품 사용 폭 760px와 280px
- 줄바꿈 모드: `wrapNames=false`, `wrapNames=true`
- 도달 가능한 상태: 정상, 불러오는 중, 읽기 전용

파일명의 최소 길이는 명시되지 않아 빈 문자열을 포함했습니다. 기존 수량 기준이 없어 현실적 수량은 3개, 10배 수량은 30개로 가정했습니다.

## 제외한 축

오류 상태는 컴포넌트 입력에 없고, 별도 테마·모션 환경은 프로젝트 지원 근거가 없어 제외했습니다. 숫자 열 정렬은 목록형 파일명 버튼에 해당하지 않습니다. 컨테이너 값은 일반 축의 320px·플렉스 압축·매우 넓은 폭 대신 사용자 범위에 명시된 실제 760px·280px를 사용했습니다.
