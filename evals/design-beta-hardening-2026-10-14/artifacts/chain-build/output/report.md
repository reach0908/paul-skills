## 남은 미결 사항

- **OD-01:** 만료된 초대 자료의 읽기 권한은 결정되지 않았다.
- **OD-02:** 인증 복구 뒤 동일 작업 키 `K`로 재조회하는 서버 API는 결정되지 않았다. 새 저장 요청이나 성공·실패를 추정하지 않는다.
- **OD-03:** 직접 URL·추천·D-SAVED에서 상세 진입 뒤의 기본 복귀 목적지와 문맥은 결정되지 않았다.
- **OD-04:** 저장 시작 뒤 메모 편집 가능 여부와 편집분 귀속은 결정되지 않았다. 기존 시안처럼 읽기 전용을 유지했다.
- 실제 원문 URL, 검색 대상 필드, 작성자 필터 URL 표현, 필터 조합, 목록별 콘텐츠 분량, D-HELP의 세부 분류는 선행 자료와 같이 미결이다.
- 프로덕션 API·실제 계정·영구 저장은 연결하지 않았고 검증하지 않았다.
- 실제 사용자 수용성은 검증하지 않았다. 이 결과는 로컬 합성 시안의 렌더링과 명시된 동작 증거다.
