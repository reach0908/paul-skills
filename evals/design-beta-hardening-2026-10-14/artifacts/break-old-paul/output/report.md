## 페이지에 포함한 시나리오

- 제목 길이: 빈 문자열, 한 단어, 일반 제목, 여러 문장(약 90자), 끊기지 않는 문자열(80자)
- 목록 수량: 0개, 1개, 현실적 수량 5개, 현실적 수량의 10배 50개
- 좁은 컨테이너: 일반 제목, 여러 문장, 끊기지 않는 문자열을 각각 320px에서 렌더링
- 코드 상태: 권한 없음, 로딩, 오류, 잠금, 새로고침

여러 문장과 끊기지 않는 문자열의 상한은 제품 제약이 없어 각각 약 90자와 80자로 가정했습니다. 제목 형태, 넓은 컨테이너, 형제에 의한 압축, 환경 모드는 요청 범위에 없거나 코드 상태가 아니어서 제외했습니다. 목록 수량과 코드 상태 시나리오에서는 추가로 보이는 깨짐이 없었습니다.
