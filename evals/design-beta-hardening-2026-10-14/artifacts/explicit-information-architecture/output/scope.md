# 정보 구조 역할 경계

## 이번 실행의 범위

이 문서는 `information-architecture` 스킬의 역할 경계만 설명한다. 제품의 정보 구조를 설계하거나, 목적지·내비게이션·화면을 제안하는 산출물은 만들지 않는다.

- 요청 출처: `TASK.md`
- 역할 정의 출처: `.agents/skills/information-architecture/SKILL.md`
- 결정 상태: 역할 경계 설명만 확정됨
- 제외: 모의 설계 과제 실행, 실제 정보 맵·사이트맵 작성, 사용자 흐름 설계, 와이어프레임, 시각 디자인, 구현, 브라우저 조작

## 이 역할이 받는 입력

실제 정보 구조 작업에서 이 역할은 합의된 제품 범위 안에서 다음 입력을 받는다.

- 제품 책임자가 정한 대상 사용자, 범위, 고정 결정과 주요 정보 탐색 과업
- 제품에서 쓰기로 한 용어와 레이블
- 콘텐츠 유형, 객체 간 관계, 식별·분류·필터링에 쓰이는 속성을 포함한 콘텐츠 목록
- 기존 제품이라면 현재 목적지와 전역·지역 내비게이션, 검색, 필터, 맥락 링크, 직접 진입 경로
- 관련 역할·권한·접근 조건
- 이미 수행된 카드 소팅이나 트리 테스트가 있다면 그 근거와 출처 식별자

입력의 출처 위치와 리비전 식별자는 유지하며, 제품 브리프를 이 역할에서 다시 쓰지 않는다. 구조에 영향을 주는 공백만 질문 대상으로 삼고, 문서가 없는 상태와 제품 결정 자체가 없는 상태를 구분한다. 권한·소유권·제품 범위가 미정이면 임의 정책을 만들지 않고 미해결 의존성으로 남긴다.

이번 실행에는 제품 브리프, 용어집, 콘텐츠 목록, 기존 내비게이션 또는 사용자 조사 자료가 제공되지 않았다. 이는 미결정 정책의 증거가 아니라 역할 경계 점검을 위해 설계 입력 문서가 범위에서 제외된 상태다.

## 이 역할이 내는 출력

실제 작업의 핵심 출력은 **콘텐츠에서 목적지까지 추적 가능한 정보 맵**이다. 일반적으로 다음을 포함한다.

- 입력 출처, 범위, 가정, 결정 상태
- 안정적인 목적지 ID, 사용자에게 보이는 레이블, 포함 콘텐츠, 지원 과업, 필요한 접근 조건
- 모든 범위 내 콘텐츠 유형의 목적지 또는 명시적 제외 사유
- 전역·지역 내비게이션, 맥락 링크, 검색, 필터, 직접 진입을 포함한 발견·복귀 관계
- 좁은 화면에서도 유지해야 할 정보 우선순위와 접근 가능 경로
- 각 탐색 과업의 진입점 → 목표 → 적절한 복귀 맥락에 대한 작성자 워크스루
- 도달 불가능한 목표, 모호한 선택지, 미해결 접근 규칙, 제안 변경과 남은 결정

목적지와 목록·상세·분류·필터는 자동으로 각각 별도 페이지가 되지 않는다. 기존 구조가 과업을 충족하면 유지할 수 있으며, 변경안은 구체적인 탐색 문제, 영향을 받는 과업, 변경 후 목적지와 함께 제시한다. 분류 체계 변경과 시각적 내비게이션 처리는 분리한다.

이번 실행의 유일한 산출물은 이 역할 경계 문서이며, 정보 맵은 산출하지 않는다.

## 인접 역할과 경계

| 역할 | 정보 구조 역할과의 관계 | 이 역할이 넘지 않는 선 |
|---|---|---|
| 제품 결정·제품 브리프 | 대상 사용자, 문제 범위, 고정 결정, 용어와 정책을 상위 입력으로 제공한다. | 제품 범위, 소유권, 권한 정책을 새로 결정하거나 브리프를 대필하지 않는다. |
| 사용자 흐름(`user-flow`) | 정보 구조가 제공한 목적지 ID와 접근 관계를 이용해 과업의 행동·결정·예외·복구 전이를 설계한다. | 클릭 이후의 상태 전이, 분기, 실패·복구 흐름을 상세 설계하지 않는다. |
| 와이어프레임(`wireframe`) | 목적지, 정보 우선순위, 진입 경로를 받아 화면 계층과 컨트롤 배치를 구체화한다. | 화면 구성, 메뉴 컴포넌트, 레이아웃, 반응형 배치를 정하지 않는다. |
| 사용자 조사 | 카드 소팅·트리 테스트 결과가 있으면 구조 결정의 근거로 활용한다. | 작성자 워크스루를 사용자 연구로 주장하지 않으며, 수행하지 않은 연구의 결과를 만들지 않는다. |
| 시각 디자인·프로토타입·구현 | 확정된 구조를 후속 표현과 제품 동작으로 옮길 수 있다. | 스타일, 고충실도 화면, 인터랙티브 프로토타입, 코드 또는 브라우저 검증을 수행하지 않는다. |

## 중단 지점

정보 구조 역할은 다음 조건에서 후속 역할로 넘긴다.

1. 정보와 탐색 과업의 범위가 한정되고, 제공된 결정과 가정이 분리되어 있다.
2. 모든 범위 내 콘텐츠가 안정적인 목적지 또는 명시적 제외에 연결되어 있다.
3. 각 목적지의 레이블, 내용, 지원 과업, 접근 조건을 식별할 수 있다.
4. 각 탐색 과업에 진입·도달·복귀 경로가 있거나, 정확한 미해결 의존성이 기록되어 있다.
5. 후속 역할이 별도의 제품 인터뷰 없이 목적지 ID를 사용할 수 있다.

구조 결정이 사용 가능하면 상태를 **후속 초안 작성 준비 완료**로 표시할 수 있다. 사용자의 명시적 결정 근거가 있을 때만 **승인됨**으로 표시한다. 차단 결정이 남으면 확정된 부분만 인계하고 필요한 결정의 정확한 내용을 기록한 뒤 멈춘다.

이 지점 이후의 과업 전이, 화면 구성, 메뉴·컨트롤 선택, 시각 표현, 프로토타입, 구현과 브라우저 검증은 요청에 별도로 포함되지 않는 한 수행하지 않는다. 이번 실행은 이 경계 설명에서 종료한다.

## 한계

- 로컬 `TASK.md`와 지정된 스킬 원문만 근거로 작성했다.
- 제품별 입력이 없으므로 실제 목적지, 레이블, 내비게이션, 접근 규칙의 타당성을 판단하거나 검증할 수 없다.
- 계정, 라이브 API, 브라우저, 외부 자료를 사용하지 않았고 사용자 조사도 수행하지 않았다.
