# Galpi exercise

This is a synthetic Korean reading-list UI. It has no backend, account, network calls or persistence; reload restores two articles. Enter an HTTPS URL for a simulated save; a URL containing `fail` simulates a failure. Removing a row affects only local memory.

The UI intentionally uses a quiet, flat style without elevated shadows. Keep its Korean voice, native browser fonts, plain HTML/CSS/JavaScript and existing tokens. This is a review task, not a redesign or implementation request.

The fixture supports desktop and narrow screens. Browser evidence must distinguish viewport resize, zoom and real mobile/assistive-technology testing. There is no framework, component library, test runner or screen-reader harness.
