# Fieldnotes 모바일 랜딩 비교 작업 보고서

## 상태와 결정 맥락

비교 시안 구현 완료. 제품안 선택, 승인, 배포는 하지 않았다. 질문은 좁은 화면에서 세 가지 이점(출처 링크 저장, 출처 옆 메모, 저장한 이유 회복)을 어떤 묶음과 순서로 설명할지다.

입력은 BRIEF.md, RESEARCH.md, 제공된 index.html이다. 기존 영문 제품 언어를 유지했다. 원본은 baseline-original.html로 보존했다. A의 header/main/footer 마크업과 문구는 보존본과 문자열 비교로 일치함을 확인했다. 비교 도구를 위한 하단 여백, 전역 box-sizing과 포커스 스타일만 공통 적용했다.

| 시안 | 구조 | 판단할 차이 |
| --- | --- | --- |
| A 기존안 | 소개 → CTA → 출처 → 메모 → 맥락 | 현재 설명을 기준으로 유지할 수 있는가 |
| B 읽기 흐름 | 소개 → 저장 → 메모 → 다시 찾기 → CTA | 세 기능이 하나의 읽기 과정으로 이해되는가. CTA에 도달하기까지 길어진다 |
| C 결과 우선 | 저장한 이유를 떠올리는 이점 → CTA → 출처와 메모 묶음 | 돌아올 때의 가치를 먼저 이해하는가. 전체 작업 순서는 덜 직접적이다 |

세 안 모두 Fieldnotes 워드마크, 크림색 배경, 초록색 강조, Start reading 문구와 #start 목적지, 세 기능 및 기기 내 저장 항목에 관한 오프라인 상태를 유지한다. 새로운 후기, 정량 성과, 전환 개선 주장은 없다. 내부 collection_id와 source_check 상태는 제품 문구에 넣지 않았다. B/C의 문구만 문장 역할과 용어를 정리했고 A는 기준으로 남겼다.

## 실행과 사용

이 폴더에서 `python3 start.py` 한 명령으로 시작한다.

- A: http://127.0.0.1:8769/?variant=A
- B: http://127.0.0.1:8769/?variant=B
- C: http://127.0.0.1:8769/?variant=C

하단 도구의 좌우 버튼이나 키보드 화살표로 순환한다. URL에 시안이 남아 새로고침해도 유지된다. 전환 도구에 현재 시안, 정보 순서, offline 상태, CTA 목적지가 표시된다. 도구는 localhost, loopback, 파일 환경에서만 나타나며 다른 호스트에서는 기존안 A만 렌더링한다. 빌드 환경이 없는 정적 fixture의 로컬 실행 제한이며 실제 배포 검증은 아니다. 데이터 저장, 백엔드, 외부 폼 전송은 없다.

## 관찰과 근거

도구는 Playwright CLI 0.1.22, Chrome 152.0.7977.82, 전용 세션 fieldnotes-forward를 사용했다. 2026-10-16 10:56 UTC에 수행했다. 320×844와 390×844로 크기를 바꾼 데스크톱 브라우저이며 실제 모바일 기기나 터치 에뮬레이션은 아니다.

- 사전 확인: 설치된 도움말 확인, 전용 세션 생성 및 다음 명령의 연결 유지, 의도한 로컬 페이지 표시 확인. 인증은 불필요하다.
- 3개 시안 × 2개 너비의 여섯 조합 완료. 문서 너비는 각각 320, 390px와 일치했다.
- 각 조합에서 CTA 문구와 #start 목적지, 오프라인 안내 존재, 세 시안 정의를 확인했다.
- 각 조합에서 실제 Tab 순서가 Start reading → Previous variant → Next variant임을 확인했다. Enter의 다음 전환, ArrowLeft의 이전 전환, 이전 버튼 클릭과 새로고침 후 상태 유지가 동작했다. 경계 A↔C 순환도 포함한다.
- C에서 CTA 클릭 시 #start로 이동했다. 나머지 시안은 같은 목적지 속성을 확인했으며 각 안에서의 CTA 클릭은 별도 실행하지 않았다.
- 전체 길이 스크린샷과 하단 스크린샷을 남겼다. 하단 안내의 바닥은 모든 경우 비교 도구 위에 있었다. 수치는 evidence/bottom-observations.txt에 있다.
- 390px 세 안의 전체 스크린샷을 직접 확인했다. B는 CTA와 오프라인 안내까지 스크롤이 필요하다. 고정 비교 바는 현재 화면 일부를 덮으며 하단 여백으로 마지막 콘텐츠를 바 위까지 스크롤할 수 있다.
- 입력 필드의 화살표 예외 처리와 로컬 호스트 제한은 소스에 구현했다. 해당 런타임 조건은 별도 실행하지 않았다.

## 파일

## 제한과 남은 결정

실제 저장, 동기화, 오프라인 보존 기능은 이 정적 시안에서 구현하거나 검증하지 않았다. 오프라인 문구는 제공된 제품 상태를 유지한 것이다. 실제 사용자 이해도, 선호도, 전환율, 실기기, 화면 낭독기, 프로덕션 환경은 미검증이다. 자연스러운 문구에 대한 판단도 사용자 검토가 남아 있다. 시각적 구조 차이는 개선의 증거가 아니다.

첫 로컬 서버 시도는 sandbox socket 권한으로 실패했다. 권한 있는 작업 전용 실행으로 복구했다. 첫 브라우저 실행은 기본 외부 캐시 위치 권한 때문에 실패했고, 작업 폴더 내 전용 daemon 캐시로 변경한 뒤 연결을 확인했다. 최초 콘솔에 favicon.ico 404 한 건이 있었으며 페이지 JavaScript 오류는 관찰되지 않았다. 지시 파일 검색 과정에서 /private/tmp 아래 파일 경로가 넓게 나열된 실수가 있었으나 다른 평가 폴더 파일 내용, 참가자 결과나 결론은 읽지 않았다.

Git 커밋, 푸시, 네트워크 조사, 패키지 설치, 외부 계정 접근은 하지 않았다. 시안 선택이 없으므로 제품 코드 승격과 원격 캡처를 진행하지 않았다. 다음 한 행동은 A/B/C를 직접 비교해 유지할 구조나 결합할 요소를 선택하는 것이다. 기존안을 유지하는 것도 유효하다.
