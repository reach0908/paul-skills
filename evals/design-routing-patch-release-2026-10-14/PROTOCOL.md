Frozen before running the release trials. The same six cases run once per host in separate neutral directories and fresh conversations, using the actual user-scope installed plugin. No plugin-dir override, trial HOME, repository skill link, model override or effort override is used. Only the explicit command prefix changes from Claude slash syntax to Codex dollar syntax.

The cases cover uncommitted and staged change routing, ordinary screen audit, an explicit better-interface request about changes, explicit interface-review preparation, and ordinary IA discovery. Six per host, twelve total. Previous 17-role evaluation remains separate; these are bounded release smoke checks, not design-quality parity or comparative model scores.

Both host installs must be enabled at version 0.4.1 with every promoted skill file and manifest byte equal to the immutable release tag. Fresh runtime catalogs must expose twelve automatic design skills, hide the five explicit-only skills from automatic reach, and make all seventeen directly discoverable. Record exact body reads or host injection, never award invocation for self-report alone.

For change-routing cases, require better-interface to load before product file inspection, preserve the target in interface-review, avoid domain review and hidden body access. Normal screen audits must not be redirected to change review. Explicit interface-review preparation must load its exact body and preserve its explicit boundary. All inputs remain unchanged.

Codex uses its read-only sandbox with no permission bypass. Each case has a six-minute timeout; stop after two environment failures. Failed outputs remain recorded, no answer-based retries. A model outcome failure blocks a clean release-validation claim, not retrospective rewriting of the case.

Publish whitelist receipts and redacted responses, protocol and source hashes, catalog names and installation file hashes. Raw transcripts, account settings and unrelated skill content stay private. Review semantic outcomes manually and label that assessment as the same agent, not an independent reviewer. Host-reported costs are estimates, not invoices. Already-open desktop conversations are outside the fresh CLI check.
