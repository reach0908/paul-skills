이 요청은 스테이징된 변경이 새로 만들었거나 악화시킨 문제, 즉 회귀를 찾는 리뷰입니다. 그래서 `better-interface`가 직접 판정하지 않고 변경 리뷰 담당 스킬로 넘깁니다. 스테이징 영역(Git index)이 대상이므로 대상 값은 `staged`입니다.

```
/paul-skills:interface-review staged
```

이 리뷰는 사용자가 직접 호출해야 해서, 위 명령을 직접 실행해 주세요. 실행할 때 지금의 조건을 그대로 적어 주시면 됩니다. 파일은 수정하지 않고, 브라우저와 추가 참가자 없이 제공된 자료 범위에서만 확인하며, 정보 위계와 3초 이해 관점의 회귀만 보고, 결과는 500단어 이내로 정리하는 조건입니다.

**근거와 확인 한계**
- 스킬 규칙상 "무엇이 도입되었거나 회귀했는가"를 묻는 요청은 `interface-review`에 맡겨야 합니다. `better-interface`를 직접 호출했거나 정보 위계 같은 분야를 지정해도 마찬가지입니다.
- 그래서 저장소, diff, 파일은 열어 보지 않았고 회귀 여부도 판정하지 않았습니다.
- 수정한 파일은 없습니다.
