# Native host review entry and local-scope trial

Freeze source and these 25 cases before model execution. Each case has a fresh native session and neutral case directory. Preserve every result, including failures. Run six pilot cases (three original staged prompts and three working-preparation prompts), then the remaining cases on the same candidate. Do not retry answers on this candidate. This is adaptive repair confirmation, not a held-out reliability estimate.

Codex uses the installed private plugin, native read-only shell, gpt-5.6-sol and inherited medium effort. This compatibility model is the supported CLI route from the preceding trials, not coverage of every desktop model. Do not impose Claude Read/Glob/Grep tools on Codex. Keep daily installs and private host auth unchanged. Claude uses its native Skill/Read/Glob/Grep and an explicit allowlist of read-only Git commands for actual handoffs. Its host-specific prompt addition is fixed in run_trials.py and recorded in receipts. Native tool differences are not skill-quality evidence.

Score exact full bodies, automatic catalog, explicit-owner expansion, entry order and source identity, read-only inputs, no failed tools, and final semantics separately. Boundary cases must stop at the correct command without repository inspection, domain loads or the execution reference. Actual handoffs must read the execution procedure and six owner bodies, complete the report and admit missing rendered evidence. Preparation-only working answers must use HEAD, zero earlier commits and include untracked files; no default-branch/merge-base prerequisite.

All Git fixtures have main behind HEAD: main lacks the name, HEAD fixes it, the index removes it. The ordinary handoff must identify a regression against HEAD. The divergent fixture restores the name in the working copy and adds an untracked unnamed button. Staged must find Panel's index regression and exclude New.html. Working must find only New.html's introduced issue and exclude the canceled Panel change. Neither local target may resolve a default branch or merge base. Assertions verify these distinct states before each run.

Limits: concurrency two per host, six minutes per session, Claude USD 1 list-cost cap for preparation, USD 4 per actual handoff, USD 20 batch stop checked between pairs. Two environment failures stop the batch. Costs are host estimates, not invoices. Public evidence excludes auth, private prompts and raw host context. Existing failures remain in the predecessor report. A release recommendation requires both hosts' final candidate gate to pass; any residual entry or scope failure holds release.
