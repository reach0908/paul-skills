# Paul Skills 0.4.3 global activation protocol

Freeze before any new native model session. User authorized official patch publication, both global user-scope installation updates, fresh-session checks and a completed report.

## Fixed sample

Run six cases once per host, twelve unique native sessions total: three exact repeats of the original color planning request, unknown image/alpha background, explicit color invocation with fully specified compositing and threshold distinctions, and staged color/type review routing. Prompts equal the six candidate cases in the pre-release color-evidence trial; the tested model sees neither graders nor previous responses. No retries to obtain a passing result. Preserve every attempt and any failure.

Codex uses the actual daily global Paul plugin 0.4.3, no CODEX_HOME override, gpt-5.6-sol with explicit xhigh effort and a read-only sandbox. Claude uses the actual user installation with no plugin-directory override, Skill/Read/Glob/Grep, strict MCP configuration, disabled hooks, and dontAsk permissions. Record actual model/effort. Use neutral empty or disposable Git case_NNN directories. Existing desktop conversations are not restarted or claimed refreshed by this test.

Maximum two concurrent cases per host, 360 seconds per case, six Codex sessions, six Claude sessions with a one-dollar per-session cap and six-dollar batch ceiling checked before each pair. Stop after two process/environment failures; model failures remain results rather than triggering retries.

## Acceptance

First verify immutable tag identity, version/workflow outcome, enabled user installation, all 175 promoted files matching the release, and unchanged evaluated skill content apart from version metadata. Verify 44 total and 17 design skills in a fresh Codex app-server catalog. Native automatic design catalogs must contain exactly 12 model-invoked skills; Claude's direct command catalog must contain all 17.

For every case verify actual expected full source loading from the installed 0.4.3 path, successful native reads, unchanged fixtures and forbidden user-only skills remaining unloaded. The explicit resolved case must read contrast.md completely. Staged review must load only better-interface and return the explicit staged review command.

The maintainer agent reviews the entire answer against the pre-release semantic rubric: no completed verification without evidence, conditional calculations stay conditional, unresolved rendered coverage stays pending through the summary, fully specified composites remain computable, active placeholder and readonly text retain applicable requirements, and disabled exemptions are justified by actual use. APCA is supplementary. Record any ancillary scope overclaim. Bind every semantic verdict to its exact response hash; missing, failed or stale reviews fail closed. This is not an independent blinded human evaluation or an automatic language judge.

## Evidence limits

Keep prior failed receipts unchanged. Successful activation and this small response sample do not establish elimination of stochastic errors, all 17 roles' outcome parity, or real product/browser contrast correctness. Publish sanitized receipts only; raw traces, host settings and authentication remain private. Report publication, installation equality and response semantics separately.
