# 사전 계획 E1
문제: AI 질문이 일반 템플릿 질문보다 문장의 이유를 떠올리는 데 도움이 되는가?
이번에는 실제 사용자 효과가 아니라 작성자 1인의 블라인드 offline 선호를 탐색한다.
가설 A1: 유효 비교 10쌍 이상에서 AI가 9쌍 이상 우세하면 이 좁은 offline 기준에서 지지. 3쌍 이하 우세면 반박. 중간 결과는 판정 불가.
같은 가상 카드 입력 12개에 baseline/후보 질문 하나씩, 무작위 순서, 작성자 평가.
유효성: 최소 10쌍, 두 출력과 판정이 모두 있는 쌍만 유효.
시도 예산: 1회. 비용 상한은 기존 무료 mock 범위만. 추가 유료 호출 없음.
종료: 한 회 완료 또는 평가자 30분 소진.
지지: offline 실패 유형을 남기고 제한된 구현을 제안. 반박: 일반 템플릿 유지. 판정 불가: 가정 미확인 유지, 일반 템플릿으로 결정된 카드 저장 기능 개발 계속. 추가 평가는 별도 후속 제안.

## 실행 후 갱신 E1-R1

- 상태: 종료, 판정 불가. `observations.json`의 E1-run-1은 실행 완료 기록이며, 이번 평가는 더 진행하지 않는다.
- 종료 근거: 시도 1회 사용과 평가자 30분 소진으로 사전 종료 조건을 모두 충족했다.
- 관측: 계획 12쌍 중 유효 7쌍. 후보 출력이 없는 5쌍은 제외. 유효 7쌍에서 후보 우세 6, 동률 1, baseline 우세 0.
- 판정: 최소 유효 10쌍을 충족하지 못해 A1의 지지 또는 반박을 판정할 수 없다. 후보 우세 6쌍도 지지 기준인 9쌍에 미달한다. 6/7의 선호 비율로 사전 기준을 대체하지 않는다.
- A1 갱신: 미확인 유지. 완성된 7쌍에서 후보를 선호한 탐색 신호는 있으나, 작성자 1인의 블라인드 offline-mock 평가 범위에 한정된다.
- 다음 행동: 사전 계획대로 일반 템플릿을 사용해 결정된 카드 저장 기능 개발을 계속한다. 현재 결과를 근거로 AI 질문 도입을 확정하지 않는다.
- 제한: 쌍별 입력, 두 출력, 판정 기록은 제공되지 않아 집계의 독립 검증과 질문 품질 실패 유형 분석이 불가능하다. 5쌍의 후보 출력 누락 원인은 미상이다. 실제 provider 실행, 실제 사용자 효과, 배포 결과는 관측하지 않았다.
- 별도 후속 제안: 기존 기록이 있으면 누락 원인과 쌍별 평가 근거를 먼저 정리한다. 추가 실행은 새 계획과 별도 권한이 있을 때만 진행하며, E1의 예산이나 판정 기준을 소급 변경하지 않는다.
