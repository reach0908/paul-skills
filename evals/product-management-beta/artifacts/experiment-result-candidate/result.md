# Pocket Cards E1 결과와 다음 행동

**E1은 지금 종료한다. 결과는 판정 불가이며, A1은 미확인으로 유지한다. 일반 템플릿을 사용한 카드 저장 기능 개발을 계속한다.** `plan.md`에 실행 후 상태, 가정, 다음 행동을 갱신했다. 원본 관측인 `observations.json`은 유지했다.

## 계획, 실행, 관측

| 구분 | 내용 |
| --- | --- |
| 검증하려던 질문 | AI 질문이 일반 템플릿보다 문장의 이유를 떠올리는 데 도움이 되는가? 이번 E1의 판단 범위는 작성자 1인의 offline 선호였다. |
| 사전 계획 | 같은 가상 카드 12개에 baseline과 후보 질문을 비교. 최소 유효 10쌍에서 AI 우세 9쌍 이상이면 지지, 3쌍 이하이면 반박, 중간이면 판정 불가. |
| 실행 | E1-run-1, offline-mock, 평가자 1명, 블라인드 순서. 시도 1회와 평가 시간 30분을 사용했다. |
| 관측 | 유효 7쌍에서 후보 우세 6, 동률 1, baseline 우세 0. 후보 출력이 없는 5쌍은 평가에서 제외됐다. |
| 종료 조건 | 한 회 완료와 평가자 30분 소진 조건을 모두 충족했다. |

근거 위치는 `plan.md`의 사전 계획 E1과 `observations.json`의 `run`, `valid_pairs`, `missing_candidate_output_pairs`, `candidate_wins`, `ties`, `baseline_wins`, `attempts_used`, `duration_minutes`다. 쌍별 원자료는 제공되지 않았다.

## 판정과 가정 갱신

유효 비교가 7쌍이므로 사전에 정한 최소 10쌍에 미달한다. 따라서 지지와 반박 어느 쪽도 선언할 수 없다. 후보 우세 6쌍 또한 지지 기준인 9쌍에 미달한다. 6/7을 비율로 환산하거나 누락 5쌍을 임의로 채워 기준을 바꾸지 않는다.

| 가정 또는 남은 질문 | 갱신 상태 | 근거와 범위 |
| --- | --- | --- |
| A1: 사전 offline 기준에서 AI 질문이 우세하다 | 미확인 | 유효 표본 부족. 완성된 7쌍의 선호는 후속 검토 가치가 있는 탐색 신호다. |
| 실제 사용자가 문장의 이유를 더 잘 회수한다 | 미확인 | 작성자 선호 평가로는 사용자 효과를 확인할 수 없다. |
| 실제 provider가 필요한 질문을 안정적으로 생성한다 | 미확인 | mock 실행이며 실제 provider 기록이 없다. 후보 출력 누락의 원인도 밝혀지지 않았다. |

작성자 1명, 가상 카드, 한 회 평가라는 범위를 넘겨 일반화할 수 없다. 누락된 5쌍 때문에 완성된 출력만을 평가한 편향 가능성이 있다. 누락은 확인된 관측이지만, 이를 실제 provider의 실패율로 해석할 근거는 없다. 쌍별 질문과 판정이 없어 질문 품질의 실패 유형, 반복 변동성, 집계의 정확성도 독립 검증하지 못했다. 계획상 표본과 임계값의 설정 근거는 자료에 없으므로 통계적 확신으로 설명하지 않는다.

## 개발을 이어가는 결정

사전 계획의 판정 불가 분기를 적용한다. 일반 템플릿으로 이미 결정된 카드 저장 기능 개발을 계속하고, AI 질문 도입은 이번 결과로 확정하지 않는다. 추가 호출이나 사람에게 연락하는 작업은 진행하지 않는다. E1을 다시 열거나 시간을 늘려 결론을 만드는 작업도 하지 않는다.

개발 담당자에게 전달할 입력은 다음과 같다.

- **가설:** AI 질문의 우세는 미확인이다. 개발 진행이 이 가설의 지지를 전제로 삼으면 안 된다.
- **현재 결정:** 질문은 일반 템플릿을 사용한다. 카드 저장 기능은 기존에 정해진 범위로 구현한다. 저장 필드나 세부 제품 규칙은 이번 자료에 없으므로 새로 확정하지 않는다.
- **필요한 확인:** 기존 저장 요구사항에 따라 카드 저장과 다시 읽기가 실제로 성립하는지 확인하고, mock 성공과 실제 저장 결과를 구분해 기록한다. 이는 구현 검증이며 AI 품질이나 사용자 효과 검증을 대신하지 않는다.
- **인계 근거:** `plan.md`의 실행 후 갱신 E1-R1, 이 결과 문서, `observations.json`의 E1-run-1.
- **남은 빈칸:** 실제 저장 요구사항과 구현 상태, 쌍별 평가 원자료, 후보 출력 누락 원인, 실제 provider와 사용자 효과에 관한 증거.

## 별도로 제안할 후속 작업

기존 기록이 남아 있다면 12쌍의 입력, 두 출력, 평가를 연결하고 누락 5쌍의 원인을 먼저 정리한다. 현재는 그 기록이 제공되지 않아 수행할 수 없다.

추가 AI 품질 평가가 필요해지면 새로운 실험으로 제안한다. 대표 입력, 평가 기준, 충분한 유효 비교 수, 누락 처리, 반복 변동성 확인, 시도·시간·비용 상한과 종료 후 행동을 실행 전에 정해야 한다. 기존 E1의 기준과 결과는 그대로 남긴다. 실제 사용자 효과가 개발 결정을 바꾸는 시점에는 별도의 사용자 관측 계획이 필요하다. 두 후속 평가 모두 현재 권한 안에서 실행하지 않는다.
