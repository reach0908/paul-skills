# Problem Brief: Pocket Cards

- **사용자와 상황:** 읽다가 나중에 다시 떠올리고 싶은 문장을 남기는 제작자 본인. 혼자 쓰는 무료 오프라인 학습 도구이며, 사업 검증은 목적이 아니다.
- **현재 문제와 대안:** 메모 앱을 열고 문장을 복사한 뒤 출처를 따로 붙이는 과정에서 기록을 포기한다. 지금의 대안은 이 수작업을 계속하거나 문장을 남기지 않는 것이다. 원하는 변화는 문장과 출처를 함께 남기고 나중에 다시 읽는 흐름을 끝까지 마치는 것이다.
- **근거와 미확인 사항:** 지난주 다섯 번 시도했고 세 번은 출처를 붙이기 전에 포기했다는 기록은 사용자의 자기 보고다. 독립 관찰 자료는 없고 프로토타입도 아직 없다. 문장과 출처를 한 흐름에서 입력하면 포기가 줄어들 것이라는 점은 가설이며, 실제 효과와 반복 사용의 유용성은 미확인이다. ([요청 근거](/private/tmp/paul-pm-beta-trial-20261014/runs/discovery-ready-candidate/task.md))
- **첫 범위:** 문장과 원문 주소 하나를 직접 입력해 저장하고, 나중에 저장된 카드를 다시 연다. 열기나 선택만으로는 저장된 카드가 되지 않으며, 저장 성공 확인 후에만 저장된 카드로 취급한다.
- **경계와 이후:** 자동 수집, 공유, AI 추천은 제외한다. 이후 범위는 본인의 실제 사용을 확인한 뒤 결정하며, 현재 추가 기능은 정하지 않는다.
- **디자인의 다음 확인:** ‘문장과 주소 직접 입력 → 저장 성공 확인 → 나중에 다시 열기’ 흐름을 검토할 수 있는 첫 프로토타입을 준비한다. 저장 전과 저장 완료를 사용자가 구분할 수 있어야 한다. 이후 본인이 실제 독서 중 사용해 문장과 출처를 함께 남기는 일을 끝내고 다시 읽을 수 있는지 확인한다.
