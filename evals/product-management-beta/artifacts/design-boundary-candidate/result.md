- **담당 역할:** `better-interface`가 레이아웃·접근성 기준과 판정을 맡고, `design-browser`가 지정된 시나리오 실행과 관측 증거 수집을 맡는다.
- **넘길 입력:** 확인할 URL 또는 실행 가능한 빌드와 버전, 카드가 표시되는 화면·콘텐츠, 저장 버튼이 나타나는 상태. 확인 기준은 ‘320px 뷰포트에서 카드가 잘리지 않음’과 ‘Tab으로 저장 버튼에 도달했을 때 초점 표시가 보임’이다.
- **완료 관측:** 320px 화면에서 카드 잘림·가로 넘침 여부를 보여주는 캡처와 재현 기록, Tab 이동 순서와 저장 버튼 초점 표시를 보여주는 기록·캡처를 받아 `better-interface`가 판정한다. 현재는 화면과 실행 기록이 없어 두 항목 모두 미확인이다.
