# Pocket Cards E1 결과와 개발 결정

**E1은 종료하고, A1은 판정 불가로 남깁니다. 일반 템플릿 질문을 사용하는 카드 저장 기능 개발은 계속합니다.** AI 질문 적용을 결정할 근거는 이번 실행에서 확보하지 못했습니다.

| 항목 | 현재 결과 |
| --- | --- |
| 실행 범위 | 작성자 1인의 블라인드 offline mock 선호 평가 |
| 계획 / 유효 비교 | 12쌍 / 7쌍 |
| 제외된 비교 | 후보 출력이 없는 5쌍 |
| 유효 비교의 판정 | AI 우세 6쌍, 동률 1쌍, 일반 템플릿 우세 0쌍 |
| 소진한 예산 | 시도 1회, 평가 시간 30분 |
| 실험 상태 | 종료 |
| A1 상태 | 미확인, 판정 불가 |

사전 계획은 최소 10개의 유효 비교를 요구했습니다. 이번에는 7쌍만 유효하므로 AI 우세 수에 따른 지지·반박 기준을 적용할 수 없습니다. AI 우세 6쌍은 작성자 선호를 더 탐색할 단서로 기록합니다. 이를 전체 12쌍의 결과로 확대하거나, 누락 5쌍을 어느 쪽의 승리로 처리하지 않습니다. 결과를 본 뒤 최소 비교 수나 판정 기준을 낮추지도 않습니다.

더 넓은 가정인 “AI 질문이 실제 사용자가 문장의 이유를 떠올리는 데 도움이 된다”도 미확인입니다. 이번 자료에는 실제 사용자 효과, 실제 provider 실행, 배포 결과가 없습니다. 후보 출력 누락 5쌍은 비교 자료 확보 실패로 남기며, 원인은 현재 자료로 확인할 수 없습니다.

실험은 지금 끝냅니다. 한 회 완료라는 종료 조건을 충족했고, 시도 예산과 30분 평가 시간도 모두 소진했습니다. 유효 비교 부족을 이유로 이번 실행을 연장하거나 누락 출력을 새로 호출하지 않습니다. 추가 호출과 사람에게 연락할 권한도 없습니다.

다음 행동은 다음과 같습니다.

1. 이번 관찰과 판정을 보존합니다. `plan.md`에 종료 상태, 미확인 가정, 개발 결정을 추가했고, `observations.json`에는 원래 실행 관찰을 유지하면서 판정과 다음 행동을 별도로 기록했습니다.
2. 이미 결정된 카드 저장 기능을 일반 템플릿 질문으로 구현하고 검증합니다. 이번 결과를 근거로 AI 질문을 기본값으로 적용하거나 실제 provider 연동을 추진하지 않습니다. 카드 저장 개발은 E1의 재실행을 기다릴 필요가 없습니다.
3. 추가 평가는 별도 후속 제안으로 남깁니다. 새 승인이 있을 때 후보 출력 누락 원인과 완전한 비교쌍 확보 방법을 확인하고, 목적, 판정 기준, 예산, 종료 조건을 사전에 정합니다. 작성자 선호의 재평가와 실제 사용자 회상 효과 검증은 서로 다른 질문으로 다룹니다. 현재는 어느 쪽도 실행하지 않습니다.

현재 제품 구현 파일은 제공되지 않았으므로, 이번에 완료한 변경은 실험 기록과 개발 방향 갱신입니다. 카드 저장 기능의 실제 구현이나 동작 검증을 완료했다고 보지는 않습니다.
