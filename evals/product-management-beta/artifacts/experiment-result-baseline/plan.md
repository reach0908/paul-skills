# 사전 계획 E1
문제: AI 질문이 일반 템플릿 질문보다 문장의 이유를 떠올리는 데 도움이 되는가?
이번에는 실제 사용자 효과가 아니라 작성자 1인의 블라인드 offline 선호를 탐색한다.
가설 A1: 유효 비교 10쌍 이상에서 AI가 9쌍 이상 우세하면 이 좁은 offline 기준에서 지지. 3쌍 이하 우세면 반박. 중간 결과는 판정 불가.
같은 가상 카드 입력 12개에 baseline/후보 질문 하나씩, 무작위 순서, 작성자 평가.
유효성: 최소 10쌍, 두 출력과 판정이 모두 있는 쌍만 유효.
시도 예산: 1회. 비용 상한은 기존 무료 mock 범위만. 추가 유료 호출 없음.
종료: 한 회 완료 또는 평가자 30분 소진.
지지: offline 실패 유형을 남기고 제한된 구현을 제안. 반박: 일반 템플릿 유지. 판정 불가: 가정 미확인 유지, 일반 템플릿으로 결정된 카드 저장 기능 개발 계속. 추가 평가는 별도 후속 제안.

## 실행 후 갱신

- 실험 상태: E1 종료. 한 회를 완료했고 시도 예산 1회를 모두 사용했으며 평가 시간도 30분에 도달했다. 유효 비교 수가 부족해도 이번 실행을 연장하지 않는다.
- 결과: 계획 12쌍 중 유효 7쌍. 후보 출력이 없는 5쌍은 제외했다. 유효 쌍의 판정은 AI 우세 6쌍, 동률 1쌍, baseline 우세 0쌍이다.
- A1 판정: 판정 불가, 가정 미확인 유지. 최소 유효 비교 10쌍을 충족하지 못했으므로 지지나 반박의 우세 수 기준을 적용하지 않는다. 기존 판정 기준은 변경하지 않는다.
- 관찰의 범위: 작성자 1인이 블라인드 순서로 평가한 offline mock 선호다. 6쌍의 AI 우세는 후속 탐색의 단서로만 남긴다. 실제 사용자의 이유 회상 효과, 실제 provider의 품질, 배포 결과는 확인되지 않았다.
- 실패 기록: 후보 출력 누락 5쌍. 원인 자료는 없어 원인을 단정하지 않는다. 누락은 비교 유효성 문제이며 baseline 우세로 바꾸거나 AI 우세로 추정하지 않는다.
- 개발 결정: 이미 결정된 카드 저장 기능을 일반 템플릿 질문으로 계속 개발한다. AI 질문의 기본 적용이나 실제 provider 연동은 이번 결과로 승인하지 않는다.
- 현재 다음 행동: 결과와 누락 유형을 보존하고, 일반 템플릿을 사용하는 카드 저장 기능의 구현 및 검증을 이어간다. 이번 실험의 재호출, 누락 출력 보충, 추가 평가자 모집은 실행하지 않는다.
- 별도 후속 제안: 새로운 평가가 승인되면 누락 원인과 완전한 비교쌍 확보 방법을 먼저 정하고, 평가 목적, 사전 판정 기준, 시도 및 시간 예산을 다시 명시한다. 작성자 선호를 재평가할지 실제 사용자 회상 효과를 검증할지도 구분한다. 현재는 제안만 남기며 시작하지 않는다.
