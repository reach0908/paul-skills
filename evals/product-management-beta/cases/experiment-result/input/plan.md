# 사전 계획 E1
문제: AI 질문이 일반 템플릿 질문보다 문장의 이유를 떠올리는 데 도움이 되는가?
이번에는 실제 사용자 효과가 아니라 작성자 1인의 블라인드 offline 선호를 탐색한다.
가설 A1: 유효 비교 10쌍 이상에서 AI가 9쌍 이상 우세하면 이 좁은 offline 기준에서 지지. 3쌍 이하 우세면 반박. 중간 결과는 판정 불가.
같은 가상 카드 입력 12개에 baseline/후보 질문 하나씩, 무작위 순서, 작성자 평가.
유효성: 최소 10쌍, 두 출력과 판정이 모두 있는 쌍만 유효.
시도 예산: 1회. 비용 상한은 기존 무료 mock 범위만. 추가 유료 호출 없음.
종료: 한 회 완료 또는 평가자 30분 소진.
지지: offline 실패 유형을 남기고 제한된 구현을 제안. 반박: 일반 템플릿 유지. 판정 불가: 가정 미확인 유지, 일반 템플릿으로 결정된 카드 저장 기능 개발 계속. 추가 평가는 별도 후속 제안.
