# 합성 책장 AI 워크스루 결과

새 AI 참여자 1명이 390×844에서 지정 과업을 124.615초, UI 조작 5회로 완료했다. 소개 화면의 `목록으로`는 직전에 보던 `내 보관함` 대신 `추천`을 표시했다. 참여자는 안내 없이 `내 보관함`을 한 번 더 선택해 원래 목록으로 복구했다. 따라서 최종 과업은 무지원 복구로 도달했지만, 직접 돌아가기의 목록 맥락 유지 의도는 이 시도와 맞지 않았다.

이는 AI 참여자 한 명의 탐색 관찰이다. 사람의 사용성, 수요, 반복 사용, 제품 승인이나 프로덕션 준비를 입증하지 않는다.

## 질문과 범위

- 실제 요청: “별의 지도를 나중에 읽기 위해 담고, 내가 담은 책에서 소개를 살펴본 뒤 방금 보던 목록으로 돌아오세요.”
- 대상: http://127.0.0.1:48617, 작은 책장 합성 프로토타입.
- 버전: 앱 revision은 제공받거나 소스를 읽지 않았다. 시작 상태를 [원본 스냅샷](participant/.playwright-cli/page-2026-10-14T09-54-50-249Z.yml)과 [첫 화면](participant/00-initial.png)으로 고정했다. 시작 스냅샷 SHA-256: `1c420685cfba17dec73b72051a37c58478a4c3f92645011745abf6999c497110`.
- 도구: playwright-cli 0.1.22, Chrome, `prototype-recheck-participant-1` 전용 세션. 브라우저 정확한 build는 미측정.
- 조건: 새 세션의 초기 화면, 390×844 viewport resize. 실제 터치 장치나 터치 에뮬레이션은 아님.
- 상한: UI 시작부터 3분 또는 UI 조작 8회 중 먼저 도달한 시점. 최초 대상 이동과 캡처는 조작 횟수에서 제외하되 벽시계 시간에는 포함.
- 실제: 2026-10-14T09:54:47.537Z부터 09:56:52.152Z, 124.615초, 5회. 도구 대기와 관찰 포함, 기한 이후 관찰 없음. UI 응답 성능 수치로 해석하지 않는다.
- 인터뷰: 원본 고정 후 같은 참여자에게 한 번, 세 질문 묶음. 추가 UI 조작 없음. 작성자 의도 공개 없음. 답변 후 소유 세션만 정상 종료.
- 추가 시도, 외부 모델 호출, 프로토타입 수정 없음.

## 독립성과 인프라

진행자는 지정 `prototype-user-test`와 그 participant/synthesis 지침, 설치된 `design-browser`, 제작자 의도만 사용해 실행을 준비했다. Skill 호출 도구가 없어 설치 지침 파일을 직접 읽었다. 작성자 의도는 진행자 전용 [author-packet.md](author-packet.md)에 두었으며, [참여자 패킷](participant/packet.md)에는 URL, 과업, 기기, 허용 행동, 상한, 세션/전송 방법만 전달했다.

`fork_turns=none`으로 fresh participant 한 명을 생성했다. 부모 대화, 제작 의도, 소스, 다른 참여자 결과를 전달하지 않았다. 참여자는 패킷과 참여자 지침, 설치된 브라우저 지침, CLI 도움말만 읽었다고 기록했다. 앱 소스, 테스트, 네트워크, 저장소 상태, 숨은 DOM을 보지 않고 접근성 스냅샷으로 행동을 선택했다. 진행자는 고정 후 스냅샷과 네 장의 상태 스크린샷을 검토해 핵심 전환을 확인했다. 참여자 자신은 저장한 스크린샷 픽셀을 별도로 보지 않았으며, 관찰 근거는 렌더된 접근성 스냅샷이었다.

인프라 준비는 과업 전에 분리했다. 기본 sandbox 셸에서 로컬 URL 연결이 즉시 거부됐으나, 승인된 호스트 셸에서 HTTP 200을 확인했다. 별도 빈 테스트 세션을 열고 서로 다른 셸 호출에서 390×844 설정과 스냅샷을 확인한 뒤 닫았다. 참여자도 자기 세션의 빈 페이지 준비를 마친 뒤 대상 이동 직전에 시계를 시작했다. 이 단계의 실패는 제품 행동으로 세지 않았다. [진행자 preflight](infrastructure/preflight.md), [참여자 setup](participant/setup.md).

절차상 한계: 진행자가 상태 확인용 `list_agents`를 한 번 호출하면서 도구가 다른 비프로토타입 작업들의 짧은 상태 요약을 자동 반환했다. 해당 실행/평가 파일을 열거나 분석에 사용하지 않았다. 이 호출은 참여자 dispatch 뒤 진행자에게만 노출됐고, fresh participant에는 전달되지 않았다. 따라서 다른 실행 자료를 전혀 보지 않았다는 절대적 주장은 하지 않는다. 원본 참여자 독립성은 이 노출과 분리된다.

## 한 번의 사후 인터뷰가 더한 정보

관찰과 회고를 분리했다. [전체 질문과 답변](participant/interview.md)은 원본 기록을 수정하지 않고 별도 저장했다.

- 담김 해석: 참여자는 확인 문구만으로 끝내지 않고, 내 보관함에서 실제 책 항목을 본 것을 근거로 현재 세션에 담겼다고 해석했다. 종료 후 보존이나 실제 독서는 확인하지 않았다고 선을 그었다.
- 돌아가기 기대: 내 보관함에서 소개를 열었고 소개에도 담은 책이라는 표시가 있어 `목록으로`를 직전 목록 복귀로 예상했다고 답했다. 추천 제목과 세 항목을 보고 기대가 어긋났다고 설명했다. 이는 원시 기록의 행동 전 기대와 일치한다.
- 복구 단서: 상단의 내 보관함 탐색과 앞서 성공한 진입 경험을 이용했다. 마지막 화면의 제목과 책 한 항목을 근거로 멈췄다. 검색·스크롤 상태 복구나 다른 경로는 알 수 없다고 답했다.

이 답변은 해당 AI의 사후 해석이며 인간의 감정, 습관 또는 선호 진술이 아니다. 제작자 설명은 끝까지 노출하지 않았다.

## 제작 의도와 비교

출처는 [작성자 초안](author-packet.md)이다. 문서 자체가 현재 제품 계약 초안이며 사용자 확정으로 취급하지 않는다.

| 의도와 출처 | 실제 결과 및 근거 | Alignment | 다음 결정 |
| --- | --- | --- | --- |
| 읽고 싶은 책을 담고 다시 찾기 | 담은 뒤 내 보관함에서 별의 지도 확인, 조작 1~2 | aligned | 이 시도의 현재 세션 내 결과로 한정 |
| 현재 세션의 내 보관함에 추가 | 목록과 소개의 담김 표시, 조작 2~3 | aligned | 영속 저장을 주장하지 않음 |
| 외부 공유 없이 담기 | 외부 전송 없음이라는 화면 안내는 보였으나 네트워크 검증은 금지 범위였음 | not reached | 실제 외부 전송 부재는 이 실행에서 미검증 |
| 보관함에서 상세 후 목록 복귀 시 보관함 유지 | 목록으로가 추천으로 이동, 조작 4. 추가 탐색 조작 5로 최종 복구 | mismatch | 초안 의도를 유지한다면 상세 진입 전 목록 맥락을 복원하는 흐름으로 수정 요청 검토 |
| 검색 조건 유지 | 검색 입력을 한 번도 하지 않았음 | not reached | 이 결과로 검색 보존 여부를 판단하지 않음 |
| 새로고침 지속성은 범위 밖 | 새로고침하지 않았음 | not reached | 범위 밖 상태를 확대 검증하지 않음 |

## 해석과 한계

과업을 이해하고 담은 책을 찾는 흐름은 안내 없이 이뤄졌다. 주요 어긋남은 상세의 직접 복귀가 목록 맥락을 잃은 한 가지 증상이다. 별도 탐색은 복구 수단으로 작동했다. 이는 최종 도달과 직접 복귀 계약 위반을 함께 보아야 하는 결과다.

다음 결정의 담당은 user-flow와 구현 소유자다. 계약 초안의 복귀 의도를 유지한다면 상세에 들어온 목록 출처를 복원하도록 변경 범위를 정할 수 있다. 검색 조건과 스크롤 보존은 이번 관찰 근거가 없으므로 확인된 결함에 포함하지 않는다. 앱 수정이나 새 참여자를 이용한 재확인은 이번 실행에서 수행하지 않았다.

- 한 명의 AI, 합성 도서 하나, 한 viewport, 한 세션, 한 과업과 한 인터뷰다. 일반화 가능한 성공률을 산출하지 않는다.
- 앱 exact revision, 브라우저 exact build, 정확한 모델/version, 비용 telemetry는 알 수 없다. 미상은 0을 뜻하지 않는다.
- 세션 종료 이후 보존, 검색 조건, 스크롤, 뒤로가기, 다른 책/경로, 키보드/실제 터치 동작은 미관찰이다.
- CLI가 console error 하나를 표시했으나 원인을 읽지 않았다. 관찰된 목록 전환의 구현 원인이나 오류와의 관계를 추정하지 않는다.
- 인터뷰 전후 원본 기록·setup·스크린샷 해시는 모두 동일했다. [원본 freeze](participant/freeze.sha256), [종료 결과](participant/session-close.md).
