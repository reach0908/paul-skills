# 요리용 로컬 체크리스트 합의 기록

상태: 초안 v1. 직접 입력 방식의 선택은 사용자 승인됨. 아래의 제안과 미정 사항은 승인된 결정과 구분한다.

## 현재 근거

이 문서는 현재 사용자 요청만을 근거로 작성했다. 이전 대화나 제품 실행 결과를 별도로 확인하지 않았다.

- E1: 현재 요청의 “목적은 업무 성과나 사업 검증이 아니라 요리하면서 종이 레시피에 표시하는 시간을 줄여 보는 개인 실험이야.”
- E2: 현재 요청의 “현재는 종이에 완료한 줄에 체크하고, 레시피 파일로 올리는 방법과 직접 짧게 입력하는 방법을 비교했어.”
- E3: 현재 요청의 “내가 직접 입력하는 로컬 체크리스트 쪽을 선택했고 이 선택은 승인했어.”
- E4: 현재 요청의 “이번 주말에 레시피 한 개를 입력해서 단계 체크와 다시 열기만 해보고 싶어.”
- E5: 현재 요청의 “로그인과 공유와 AI 자동 추출은 제외하기로 했고, 기기 간 동기화는 미정이야.”
- E6: 현재 요청의 “지금은 합의 기록 초안과 다음 단계 입력까지만 준비해줘. 코드를 만들거나 다음 단계를 실행하지 마.”

## 합의 기록

- **목적 | 사용자 결정, E1:** 요리 중 종이 레시피에 표시하는 시간을 줄여 보는 개인 실험이다. 업무 성과나 사업 검증을 성공 조건으로 삼지 않는다.
- **사용 장면과 현재 대안 | 사용자 보고, E2:** 사용자가 요리하면서 종이 레시피의 완료한 줄에 체크하고 있다. 종이를 그대로 사용하는 방식이 현재 대안이다.
- **선택 | 사용자 결정 및 승인, E3:** 사용자가 직접 짧게 입력하는 로컬 체크리스트를 선택했다. 이번 주말에 직접 한 개를 입력해 보려는 범위와 연결된다(E4).
- **비교한 다른 방향 | 사용자 보고, E2~E3:** 레시피 파일 업로드도 비교했으나 이번 선택에서 채택하지 않았다. 배제의 구체적인 비교 이유는 제공되지 않았다.
- **첫 범위 | 사용자 결정, E4:** 이번 주말에 레시피 한 개를 입력하고, 단계를 체크하고, 다시 열어 본다. 전체 레시피 관리나 추가 기능으로 범위를 늘리지 않는다.
- **제외 | 사용자 결정, E5:** 로그인, 공유, AI 자동 추출은 이번 범위에서 제외한다.
- **보류 | 사용자 결정, E5:** 기기 간 동기화는 미정으로 둔다. 로컬 선택을 동기화의 영구 제외로 해석하지 않는다.
- **행동 의미 | 확정 범위와 미정의 구분, E2~E4:** 레시피, 그 안의 단계, 단계의 체크가 핵심 대상이다. 단계 체크와 레시피 전체 완료는 별개이며, 전체 완료 규칙은 정해지지 않았다. 다시 열 때 레시피 내용과 체크 상태를 어느 범위까지 유지할지, 체크 해제와 새 요리 시작 시 초기화 방식도 미정이다.
- **관찰 | AI 제안, E1·E4에서 도출:** 직접 입력에 드는 수고와 요리 중 체크가 종이보다 덜 번거로운지, 다시 열기에서 기대한 정보를 찾을 수 있는지 짧게 기록한다. 시간의 기준값과 실제 사용 결과는 없다.
- **전제 | 미검증:** 작은 로컬 체크리스트가 사용자의 개인 실험에 유용할 수 있다는 기대다. 구현물, 저장 동작, 사용 편의와 시간 감소는 아직 확인하지 않았다.

## 다음 단계 입력, 미실행

다음 담당은 범위를 좁힌 흐름 설계 세션이다. 입력 문서는 이 파일의 초안 v1과 E1~E6이다. 사용자에게 승인된 선택을 다시 묻지 않고, 첫 흐름을 구체화하는 데 필요한 미정 사항만 다룰 수 있다. 화면 구성과 기술 선택은 아직 없다.

준비한 요청문:

> 이 합의 기록 초안 v1을 기준으로, 이번 주말에 레시피 한 개를 직접 입력하고 단계를 체크한 뒤 다시 여는 흐름 초안만 정리해줘. 승인된 직접 입력 방식과 로그인·공유·AI 자동 추출 제외 결정을 유지해줘. 다시 열 때 내용과 체크 상태가 유지되는 범위, 체크 해제와 초기화는 미정으로 표시하고 필요한 결정만 좁혀줘. 동기화는 미정으로 남겨줘. 코드를 만들거나 구현을 시작하지 마.

이 단계는 승인된 범위의 흐름 초안을 시작할 수 있다. 다시 열기의 유지 범위는 저장 동작을 확정하기 전에 사용자 결정이 필요하다. 완료 신호는 입력, 단계 체크, 종료와 다시 열기의 흐름 및 미정 사항을 구분한 짧은 초안이다. 이 요청문은 준비만 했으며 실행하지 않았다.

## 검토와 한계

자체 점검으로 목적, 승인된 선택, 제외 범위, 미정 사항과 다음 입력의 일관성을 확인했다. 독립 검토는 수행하지 않았다. 이 문서는 기록과 다음 설계 입력이며, 구현 완료나 사용자 사용 검증을 뜻하지 않는다.
