# 디자인 리뷰 호출 경계 수정과 승격 재판정

2026-10-14 KST. `better-interface`와 `interface-review`의 호출 경계를 수정하고 첫 승격 후보 9개를 재검증했다. 실제 폴더 이동이나 정식 릴리스는 이 작업에 포함하지 않는다.

## 수정한 동작

`better-interface`는 파일을 읽기 전에 화면 검토와 변경 검토를 구분한다. 이름 없는 변경 요청은 사용자가 직접 호출할 명령을 안내하고 끝낸다. 자동 선택 목록에서 `interface-review`가 보이지 않아도 미설치로 단정하거나 자체 diff 리뷰로 대체하지 않는다. 스테이징은 `staged`, 전체 미커밋 변경은 `working`으로 안내한다.

`interface-review`는 사용자가 이름을 명시한 경우에만 시작한다. 이후 사용자 호출, 확정한 범위, 영향받는 화면, 검증 제약과 발견 사항의 상태를 `better-interface`에 넘긴다. 받은 쪽은 같은 호출을 다시 요구하지 않고 여섯 분야를 검토한다.

변경한 후보 파일은 두 `SKILL.md`뿐이다. 나머지 7개 후보 파일은 직전 설치 검증과 해시가 같다. 종합 리뷰의 기존 3단계 이후 규칙, 변경 리뷰의 범위 해석·분류 규칙과 최종 보고 형식도 그대로다. 출처 기록에는 로컬 보완을 추가했으며 Jakub 원본의 import/review revision은 `d574cc8a576dc24256ad38268b8d03d86724a1b3`에서 이동시키지 않았다.

## 설치와 실행 조건

현재 작업 트리의 기존 정식 경로 27개와 후보 9개를 합친 36개 시험 플러그인을 별도 `CODEX_HOME`에 실제 설치했다. 스킬 파일 143개를 고정했고 캐시와 해시를 대조한다. 모든 모델 실행은 대화 이력이 없는 새 Codex CLI 문맥이다. 실제 사용 모델은 앞선 CLI 검증과 같은 `gpt-5.6-sol`, 추론 설정은 `xhigh`다.

자동 선택 목록에는 디자인 후보 8개가 제공되고 직접 호출 전용 `interface-review`는 제외된다. 설치 카탈로그에서는 9개 모두 확인된다. 명시 호출에서는 숨겨진 스킬을 정상 로딩한다. 이는 Codex 데스크톱의 새 채팅 UI 또는 Claude Code 모델 실행의 증거는 아니다. Claude 검사는 시험 패키지의 `--strict` 검증이다.

입력은 앞선 [설치 검증](../design-install-discovery-2026-10-14/REPORT.md)의 화면과 프롬프트를 재사용했다. 미커밋 요청은 두 독립 문맥으로 반복하고 스테이징 전용 요청을 추가했다. 화면 리뷰는 소스만 읽도록 지정했다. 새 브라우저 실행이나 Playwright QA 결과를 주장하지 않는다.

## 실패 기록과 최종 검증

첫 수정본은 미커밋 요청 두 번을 모두 안내에서 종료했지만, 스테이징 요청에도 `working`을 안내했다. 요청보다 넓은 범위를 검토할 수 있으므로 실패다. 대상 매핑을 명시해 수정했다.

첫 수정본의 일반 화면 리뷰에는 키보드·가로 넘침·글꼴 문제만 남고 중복 상세 내용의 문구 문제가 빠졌다. 이 누락도 보존했다. 그 관찰 뒤 기존 유효 발견 4개의 유지 여부를 보조 기준으로 추가하고, 최종본의 일반 화면 리뷰를 한 번 더 독립 실행했다. 같은 노출 과제의 반복이며 숨겨진 평가나 통계적 성공률로 보지 않는다.

최종 수정본은 **7개 새 문맥에서 7개 모두 통과**했다. 첫 수정본 6개를 포함해 이번 작업의 실행은 총 13개다. 첫 수정본은 호출·리뷰 기준을 합치면 4/6, 최종본은 7/7이며 실패 기록을 제외하지 않았다.

| 최종 사례 | 결과 |
| --- | --- |
| 이름 없는 미커밋 변경, 첫 실행 | `interface-review working` 안내만 반환. 실제 diff·소스 검토와 판정 없음 |
| 같은 미커밋 요청, 별도 새 문맥 | 같은 종료 경계 재현 |
| 이름 없는 스테이징 변경 | `interface-review staged` 안내만 반환. `working`으로 범위를 넓히지 않음 |
| 일반 화면 리뷰 | `better-interface`와 6개 도메인 로딩. 키보드·가로 넘침·중복 상세 내용·기본 글꼴 설정의 4개 유효 발견 유지 |
| 일반 화면 리뷰, 별도 새 문맥 | 같은 4개 유효 발견 유지. 문구와 글꼴의 심각도는 실행별 차이 있음 |
| 명시한 `interface-review working` | 원래 범위를 해석한 뒤 종합 리뷰로 연결. 키보드 `Regression`과 기존 레이아웃 문제를 구별하고 다시 명시 호출을 요구하지 않음 |
| 관련 없는 산술 | 도구 없이 `102` 반환 |

안내에서 끝난 최종 3개 사례는 각각 `better-interface/SKILL.md` 읽기 명령 1개만 실행했다. 숨겨진 `interface-review`를 찾거나 대신 diff를 검토하지 않았다. 검토 사례의 `Block`은 결함을 넣은 화면을 올바르게 거부한 결과이며 스킬 검사 실패가 아니다.

최종 36개 카탈로그와 143개 설치 파일 해시가 일치했고 테스트 화면은 변경되지 않았다. 두 시험 패키지 모두 `claude plugin validate --strict`를 통과했다. 저장소 `npm run check`는 출처 기록 56개, 정식 경로 27개, 테스트 36개를 통과했다.

## 승격 판단

**첫 후보 9개 모두 정식 승격을 권고한다.** 이전 판단에서 남았던 두 스킬의 호출 경계 결함을 수정했고, 정상 리뷰 경로와 발견 유지까지 재확인했다. 앞서 검증한 7개 후보의 파일은 그대로다.

| 후보 | 판단 근거 |
| --- | --- |
| `better-interface` | 변경 요청의 종료 경계 통과. 최종 일반 리뷰 두 번 모두 6개 도메인과 4개 유효 발견 유지 |
| `interface-review` | 사용자 명시 호출, 범위 확정, 종합 리뷰 전달과 변경 책임 분리 통과 |
| `better-accessibility`, `better-layout`, `better-writing`, `better-typography`, `better-colors`, `better-ui` | 기존 대표 원본 비교·현장 근거에 더해 최종 화면 리뷰와 변경 리뷰에서 실제 로딩 및 관련 발견 확인 |
| `design-browser` | 직전 실제 QA와 설치 검증 근거 유지. 이번에는 파일 불변과 설치·발견을 확인했으며 브라우저 동작을 새로 실행하지 않음 |

이는 로컬 기반 반응형 웹과 평가한 과제 범위의 출시 판단이다. 나머지 8개 후보는 이번 승격 권고에 포함하지 않는다. 모든 후보는 현재도 `skills/in-progress/`에 있으며 실제 정식 승격, 릴리스 버전 변경, 글로벌 설치 갱신은 실행하지 않았다.

시험용 인증 연결 두 개는 실행 후 제거했다. 전역 Paul 플러그인은 Codex와 Claude 모두 0.2.0의 27개이며, 시험 마켓플레이스가 전역 설정에 추가되지 않았음을 확인했다. [판정 데이터](evidence/assessment.json), [전역 상태](evidence/global-state.json), [정리 기록](evidence/cleanup.json).

## 근거와 판정 범위

이번 변경에서 원본 전체 비교를 다시 실행하지 않았다. [17역할 대표 원본 비교](../design-role-parity-2026-10-12/RESULTS.md), [INFLFEED QA 보완](../design-field-trial-2026-10-14/QA-REPAIR.md), 직전 설치 검증과 로드맵 현장 검증을 기존 근거로 삼고, 새 실행은 변경된 호출 분기와 정상 리뷰의 회귀를 검증한다. 과거 실행을 수정된 두 파일의 새 실행으로 바꿔 세지 않는다.

원본 이상이라는 기준은 대표 비교에서 확인한 유효 결과를 유지해야 한다는 출시 기준으로 적용한다. 모든 입력에서 원본 이상, 모든 표현의 자동 선택, 모든 모델·브라우저·보조기술에서의 동일 결과를 보증하지 않는다. 첫 실행의 문구 누락과 심각도 차이는 모델 출력의 변동성으로 남긴다.
