# Design

User experience, interaction, visual design, and design evaluation. Product strategy and prioritization belong in `product-management/`; general engineering implementation belongs in `engineering/`. `build-design` owns implementing an approved visual reference and checking its fidelity.

Seventeen skills were promoted with explicit user approval. The [first nine](../../evals/design-promotion-2026-10-14/REPORT.md) cover review and browser evidence; the [remaining eight](../../evals/design-final-promotion-2026-10-14/REPORT.md) add planning, component workbenches and design implementation. These records distinguish source comparisons, behavior checks and installation evidence.

## User-invoked

- **[state-machine](./state-machine/SKILL.md)**: Render reachable component states with real components, local fixtures and a switcher on a removable workbench.
- **[break](./break/SKILL.md)**: Stress a real component with plausible hostile content on one temporary page and report observed breakage.
- **[variant](./variant/SKILL.md)**: Compare one component along a chosen design axis in its real page while preserving task state.
- **[interface-review](./interface-review/SKILL.md)**: Review a branch, pull request or uncommitted change, separating introduced and regressed findings from existing problems.

## Model-invoked

- **[information-architecture](./information-architecture/SKILL.md)**: Map agreed content to stable destinations, labels and navigation paths.
- **[user-flow](./user-flow/SKILL.md)**: Specify task actions, transitions, feedback and recovery, including exit and return without losing state.
- **[wireframe](./wireframe/SKILL.md)**: Build interactive low-fidelity screens and Markdown specifications from agreed content and flows.
- **[build-design](./build-design/SKILL.md)**: Implement an approved local prototype, screen specification or design reference with existing tokens and components.
- **[better-interface](./better-interface/SKILL.md)**: Combine six domain reviews into one evidence-backed interface report; route unnamed changes to explicit interface-review.
- **[better-accessibility](./better-accessibility/SKILL.md)**: Check semantics, names, keyboard and focus behavior, forms, announcements, motion preferences and zoom.
- **[better-layout](./better-layout/SKILL.md)**: Check grouping, alignment, reading order and responsive structure under resizing, translation and RTL.
- **[better-writing](./better-writing/SKILL.md)**: Write and review interface copy that matches the product voice, actual behavior and recovery paths.
- **[better-typography](./better-typography/SKILL.md)**: Check type scale, font behavior, wrapping, truncation, text selection and language-aware rendering.
- **[better-colors](./better-colors/SKILL.md)**: Build and audit semantic color roles and palettes, and measure contrast without replacing a consistent project system.
- **[better-ui](./better-ui/SKILL.md)**: Polish surfaces, icons and motion while preserving working interactions, geometry and project conventions.
- **[design-browser](./design-browser/SKILL.md)**: Collect bounded browser evidence using Playwright CLI for QA and Aside for research and general browsing.
- **[explain-interface](./explain-interface/SKILL.md)**: Explain a site or effect with measured, derived and inferred evidence, without claiming an image reveals its source.
