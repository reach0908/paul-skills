# Design

User experience, interaction, visual design, and design evaluation. Product strategy and prioritization belong in `product-management/`; implementation belongs in `engineering/`.

Nine review and browser-evidence skills were promoted after user approval. The [promotion record](../../evals/design-promotion-2026-10-14/REPORT.md) links their source comparisons, field checks and fresh-session evidence. Remaining design experiments stay in `in-progress/` and outside the plugin.

## User-invoked

- **[interface-review](./interface-review/SKILL.md)**: Review a branch, pull request or uncommitted change, separating introduced and regressed findings from existing problems.

## Model-invoked

- **[better-interface](./better-interface/SKILL.md)**: Combine six domain reviews into one evidence-backed interface report; route unnamed changes to explicit interface-review.
- **[better-accessibility](./better-accessibility/SKILL.md)**: Check semantics, names, keyboard and focus behavior, forms, announcements, motion preferences and zoom.
- **[better-layout](./better-layout/SKILL.md)**: Check grouping, alignment, reading order and responsive structure under resizing, translation and RTL.
- **[better-writing](./better-writing/SKILL.md)**: Write and review interface copy that matches the product voice, actual behavior and recovery paths.
- **[better-typography](./better-typography/SKILL.md)**: Check type scale, font behavior, wrapping, truncation, text selection and language-aware rendering.
- **[better-colors](./better-colors/SKILL.md)**: Build and audit semantic color roles and palettes, and measure contrast without replacing a consistent project system.
- **[better-ui](./better-ui/SKILL.md)**: Polish surfaces, icons and motion while preserving working interactions, geometry and project conventions.
- **[design-browser](./design-browser/SKILL.md)**: Collect bounded browser evidence using Playwright CLI for QA and Aside for research and general browsing.
