# Korean interface copy

Read the existing product terminology and speech level first. Match its established 해요체 or 합니다체 in sentences and its convention for short action labels. A single control does not establish a new voice.

Name actions in natural Korean word order. Use "저장" or "초안 저장" when that is what the control does. Use "삭제 취소" only when the action restores the deleted item. Check the behavior, not a literal English translation.

Keep message templates whole. Particles around user-supplied names need a locale-aware message or a sentence that avoids a particle choice. Do not concatenate fragments that assume a particular final consonant.

Use the product's Korean nouns consistently across navigation, cards and errors. Retain established product names and code identifiers in their original spelling. Check mixed Korean, Latin, numbers and URLs with realistic lengths.

An error names the failure and a recovery the interface actually offers. A filtered empty state preserves the query and offers a way to change or clear it. Text rendering and wrapping belong to `better-typography`.
